## 🔍 深入分析

### 为什么只有 n_stocks 敏感？

#### 1. IC相同的原因

所有参数组合的IC IR都是0.5255，这说明：
- **因子预测能力不变**: IC只取决于模型预测，与组合构建无关
- **组合构建参数**: 只影响如何将预测转化为收益，不影响预测本身

#### 2. n_stocks 影响收益的机制

**持仓数量影响**:
- **30-40只**: 集中度过高 → 个股风险大 → Sharpe低
- **50-60只**: 适度分散 → 风险收益平衡
- **80-100只**: 充分分散 → 捕获更多alpha → Sharpe高

**数学原理**:
```
Sharpe = (收益 - 无风险利率) / 波动率

持仓越多:
- 收益: 捕获更多因子alpha ↑
- 波动率: 个股风险分散 ↓
- 结果: Sharpe ↑
```

#### 3. 其他参数为何无影响？

**max_single_weight (0.02-0.05)**:
- 在50只股票下，等权重 = 1/50 = 0.02
- 测试范围都大于等权，实际约束不起作用

**max_turnover (0.2-0.4)**:
- 策略本身换手率可能远低于0.2
- 约束不起作用

**max_single_family_weight (0.3-0.5)**:
- 因子族权重可能本身就很分散
- 约束不起作用

**weight_smoothing_halflife (2-8)**:
- 在月度调仓下，平滑效果差异不大
