## A价值树 (A_value)

**核心理念**: 市场给这家公司定价是不是过低了

### 分支结构

| 分支 | 名称 | 核心逻辑 |
|-----|------|---------|
| A1 | 低PE/PB/PS | 最经典的价值分支，低估值筛选 |
| A2 | 高股息/现金流价值 | 稳定分红、现金流优异的公司 |
| A3 | 深度价值/资产折价 | 安全边际够厚 |
| A4 | 价值修复 | 便宜+催化因素 |

### 筛选条件

#### 估值类（核心）

| 条件 | 参数范围 |
|-----|---------|
| 市盈率大于0小于X | 15-50 |
| 市净率小于X | 1-3 |
| 市销率小于X | 1-5 |
| 股价小于每股净资产（破净） | - |
| 总市值小于净资产 | - |

#### 盈利质量类

| 条件 | 参数范围 |
|-----|---------|
| 净资产收益率大于X% | 8-15% |
| 最近X年净利润为正 | 2-5年 |
| 经营活动产生的现金流量净额大于净利润 | - |
| 自由现金流为正 | - |

#### 股息类

| 条件 | 参数范围 |
|-----|---------|
| 股息率大于X% | 2-5% |
| 近X年连续分红 | 2-3年 |
| 分红率大于X% | - |

#### 安全边际类

| 条件 | 参数范围 |
|-----|---------|
| 资产负债率小于X% | 40-70% |
| 流动比率大于X | 1.2-2 |
| 速动比率大于X | - |

#### 修复信号类

| 条件 | 参数范围 |
|-----|---------|
| 近X日跌幅大于X% | 40-90日，15-35% |
| 最近X季度净利润同比增长率持续改善 | - |
| 股价站上20日均线 | - |

#### 排序条件

- 市盈率从低到高
- 市净率从低到高
- 股息率从高到低
- 市值从小到大

## B质量成长树 (B_quality_growth)

**核心理念**: 好公司能不能持续变得更好，并且这种变好能不能兑现到股价

### 分支结构

| 分支 | 名称 | 核心逻辑 |
|-----|------|---------|
| B1 | 稳定高ROE | ROE的稳定性与质量 |
| B2 | 营收与利润持续增长 | 增长是否真实可持续 |
| B3 | 高毛利高净利 | 护城河强弱 |
| B4 | 现金流质量成长 | 利润质量最重要 |
| B5 | 戴维斯双击 | 盈利+估值双重收益 |

### 筛选条件

#### ROE/盈利质量类（核心）

| 条件 | 参数范围 |
|-----|---------|
| 净资产收益率大于X% | 10-20% |
| 连续X年ROE大于Y% | X:3-5, Y:12-18% |
| ROIC大于X% | 8-15% |
| 净利润率大于X% | 8-15% |
| 总资产周转率稳定 | - |
| 资产负债率小于X% | 40-70% |

#### 增长类

| 条件 | 参数范围 |
|-----|---------|
| 最近X季度营业收入同比增长率均大于Y% | X:4-8, Y:15-30% |
| 最近X年营业收入增长率大于Y% | X:2-3, Y:10-25% |
| 营收同比增长率大于X% | 15-30% |
| 扣非净利润增长大于X% | 20-50% |
| 营收增长小于净利润增长 | - |

#### 毛利率/净利率类

| 条件 | 参数范围 |
|-----|---------|
| 毛利率大于X% | 30-50% |
| 净利率大于X% | 10-20% |
| 最近三年毛利率保持稳定 | - |
| 毛利率高于行业中位数 | - |

#### 现金流质量类

| 条件 | 参数范围 |
|-----|---------|
| 经营活动产生的现金流量净额大于净利润 | - |
| 经营活动产生的现金流量净额连续X年为正 | X:2-3年 |
| 应收账款增长率小于营业收入增长率 | - |
| 货币资金减去负债总计大于1 | - |

#### 估值类（戴维斯双击分支）

| 条件 | 参数范围 |
|-----|---------|
| 市盈率大于0小于X | 20-30 |
| PEG小于X | 0.8-1.5 |
| 市净率小于X | 2-4 |
| 净利润同比增速递增 | - |

#### 排序条件

- 净资产收益率从高到低
- 净利润增长率从高到低
- ROIC从高到低
- 毛利率从高到低

## C小盘树 (C_small_cap)

**核心理念**: 小市值公司为什么更容易产生大收益，以及为什么也更容易产生大回撤

### 分支结构

| 分支 | 名称 | 核心逻辑 |
|-----|------|---------|
| C1 | 小市值价值 | 关注度低容易被错定价 |
| C2 | 小市值成长 | 业绩改善时弹性最大 |
| C3 | 小盘错杀 | 被无差别抛售后的机会 |
| C4 | 小盘流动性与拥挤度 | 流动性风险控制 |

### 筛选条件

#### 市值类（核心）

| 条件 | 参数范围 |
|-----|---------|
| 流通市值大于X亿元小于Y亿元 | X:5-20, Y:30-80 |
| 总市值小于X亿元 | 30-100亿 |
| 股价小于X元 | 10-30元 |

#### 估值类

| 条件 | 参数范围 |
|-----|---------|
| 市盈率大于0小于X | 15-40 |
| 市净率小于X | 1-3 |
| 市销率小于X | 1-5 |
| 动态市盈率小于行业中位数 | - |

#### 成长类

| 条件 | 参数范围 |
|-----|---------|
| 营收同比增长率大于X% | 15-50% |
| 净利润同比增长率大于X% | 20-60% |
| 最近三年营业收入增长率大于X% | 10-25% |

#### 流动性类

| 条件 | 参数范围 |
|-----|---------|
| 最近20日日均成交额大于X万元 | 2000-8000万 |
| 换手率大于X%小于Y% | X:1-3, Y:6-15% |
| 股东户数下降率小于-X% | 5-20% |

#### 错杀类

| 条件 | 参数范围 |
|-----|---------|
| 近X日跌幅大于Y% | X:40-90, Y:15-35% |
| 相对发行价涨跌幅小于0（破发） | - |
| 股价小于每股净资产（破净） | - |

#### 盈利质量类

| 条件 | 参数范围 |
|-----|---------|
| 净资产收益率大于X% | 8-15% |
| 经营活动产生的现金流量净额大于0 | - |
| 毛利率大于X% | 20-40% |

#### 排序条件

- 市值从小到大
- 市盈率从低到高
- 净利润同比增长率从高到低
- 换手率从低到高

## D错杀反转树 (D_mispricing_reversal)

**核心理念**: 市场是不是把一个问题定价得过重了

### 分支结构

| 分支 | 名称 | 核心逻辑 |
|-----|------|---------|
| D1 | 破发反转 | 股票跌破发行价后的修复机会 |
| D2 | 大跌后修复 | 股价大幅下跌后的修复机会 |
| D3 | 基本面强+股价弱 | 业绩不差但股价表现差 |
| D4 | 困境反转 | 最差阶段可能已过去 |

### 筛选条件

#### 错杀信号类（核心）

| 条件 | 参数范围 |
|-----|---------|
| 相对发行价涨跌幅小于0（破发） | - |
| 近X日跌幅大于X% | 大跌后修复，20-60日，15-30% |
| 近X个月股价跌幅最大 | - |
| 近X日股价跌幅大于板块平均 | - |

#### 基本面改善类

| 条件 | 参数范围 |
|-----|---------|
| 净利润同比增长率大于X% | 20-50% |
| 营业收入同比增长率大于X% | 10-30% |
| 最新年报扭亏为盈 | - |
| 扣非净利润同比转正 | - |
| 最近X季度净利润同比增长率均为正 | - |

#### 现金流质量类

| 条件 | 参数范围 |
|-----|---------|
| 经营活动产生的现金流量净额大于0 | - |
| 经营活动产生的现金流量净额大于净利润 | - |
| 资产负债率下降 | - |

#### 估值安全类

| 条件 | 参数范围 |
|-----|---------|
| 市盈率大于0小于X | 20-35 |
| 市净率小于X | 1.5-3 |
| 股价小于每股净资产（破净） | - |

#### 修复信号类

| 条件 | 参数范围 |
|-----|---------|
| 股价重新站上20日均线 | - |
| 最近X季度净利润同比增长率持续改善 | - |
| 股价仍处于近一年低位 | - |

#### 排序条件

- 近X日跌幅从大到小（跌幅越大排序越靠前）
- 净利润同比增长率从高到低
- 市盈率从低到高

## H复合策略树 (H_composite)

**核心理念**: 单一因子很容易失效，几棵树的交叉才能稳定

### 分支结构

| 分支 | 名称 | 核心逻辑 |
|-----|------|---------|
| H1 | 价值+成长 | 低估值成长，PEG思路 |
| H2 | 基本面+资金面 | 先有研究价值再有资金确认 |
| H3 | 基本面+技术面 | 基本面决定该不该看，技术决定何时上车 |
| H4 | 错杀+技术确认 | 先找跌错的再等趋势转强 |
| H5 | 事件+质量过滤 | 先找事件催化再过滤垃圾票 |

### 筛选条件

#### 三层结构

复合策略由三层组成：

| 层级 | 作用 | 典型条件 |
|------|------|---------|

## I组合风控树 (I_portfolio_risk)

**核心理念**: 选股解决"选什么"，组合树解决"怎么拿"

### 分支结构

| 分支 | 名称 | 核心逻辑 |
|-----|------|---------|
| I1 | 股票池构建 | 决定研究哪一类股票 |
| I2 | 排名与打分 | 排序规则 |
| I3 | 持仓与调仓 | 仓位管理 |
| I4 | 风险过滤 | 统一排雷层 |
| I5 | 组合层面管理 | 整体组合控制 |

### 筛选条件

#### 股票池基础类

| 条件 | 参数范围 |
|-----|---------|
| 非ST | - |
| 非退市 | - |
| 非停牌 | - |
| 流通市值大于X亿元 | 5-50亿 |
| 最近一年净利润为正 | - |

#### 流动性类

| 条件 | 参数范围 |
|-----|---------|
| 最近20日日均成交额大于X万元 | 1000-10000万 |
| 换手率大于X% | 1-5% |

#### 风险过滤类

| 条件 | 参数范围 |
|-----|---------|
| 近1个月有减持公告取反 | - |
| 资产负债率小于X% | 50-80% |
| 经营现金流量净额不连续两年为负 | - |
| 非重大财务造假风险 | - |

#### 排序条件

| 条件 | 参数范围 |
|-----|---------|
| 市盈率从低到高 | - |
| 市净率从低到高 | - |
| 净利润同比增长率从高到低 | - |
| 市值从小到大 | - |
| 主力资金流向/流通市值从大到小 | - |

## 通用排雷条件

所有树通用，建议作为基础筛选层：

| 条件 | 说明 |
|-----|------|
| 非ST | 排除ST股票 |
| 非退市 | 排除退市风险股 |
| 非停牌 | 排除长期停牌股 |
| 流通市值大于X亿元 | 流动性要求，通常5-50亿 |
| 资产负债率小于X% | 财务风险控制，通常40-80% |
| 经营活动产生的现金流量净额大于0 | 现金流质量 |
| 最近X年净利润为正 | 盈利稳定性，通常2-5年 |

## 评分公式

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 5:
    position_penalty = (5 - maxPositions) ** 2 * 0.1
elif maxPositions > 15:
    position_penalty = (maxPositions - 15) ** 2 * 0.01
else:
    position_penalty = 0

# 过拟合惩罚（v3新增，部分树）
overfit_penalty = 持股少时胜率不足的惩罚

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty - overfit_penalty
```

### 过拟合惩罚规则（持股少于5支时）

| 持股数 | 要求胜率 |
|-------|--------|
| 1支 | ≥60% |
| 2支 | ≥55% |
| 3支 | ≥50% |
| 4支 | ≥45% |
| ≥5支 | 无限制 |

### 硬约束

- `abs(max_drawdown) > 0.35` 直接rollback
- 新score **严格大于** championscore才keep
