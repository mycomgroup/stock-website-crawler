## 为什么必须研究复合策略

单一因子很容易失效。

真正稳定的研究体系，往往不是：

- 只看便宜
- 只看技术
- 只看资金

而是几棵树的交叉。

复合策略的核心优势：
- **降低单一因子失效风险**：多个条件互相验证
- **提高信号质量**：交叉验证比单一信号更可靠
- **适应不同市场环境**：复合条件在不同环境下有不同收益来源

## H树的五个分支

### H1. 价值 + 成长

最经典也最实用的主干。

适合研究：
- 低估值成长
- PEG 思路
- 盈利增长快于估值扩张

**自然语言条件样例：**

```

非ST，PEG小于1，ROE大于12%，近两年经营现金流为正

非ST，市净率小于2，最近三年营业收入增长率大于15%，最近三年净利润增长率大于20%
```

### H2. 基本面 + 资金面

逻辑：先有研究价值，再有资金确认。

很适合 A 股。

**自然语言条件样例：**

```

非ST，市盈率小于20，股东户数下降率小于-10%，机构持股比例增长值大于0

非ST，毛利率大于30%，前十大流通股东包含社保基金，近20日涨跌幅为正
```

### H3. 基本面 + 技术面

逻辑：
- 基本面决定该不该看
- 技术面决定何时上车

**自然语言条件样例：**

```
非ST，ROE大于12%，净利润同比增长率大于20%，股价站上20日均线

非ST，营收同比增长率大于30%，毛利率大于30%，MACD金叉

非ST，市盈率小于25，经营现金流为正，5日均线上穿20日均线
```

### H4. 错杀 + 技术确认

逻辑：
- 先找跌错的
- 再等趋势止跌或转强

**自然语言条件样例：**

```

非ST，破发，营业收入同比增长率大于10%，MACD金叉

非ST，近4个月股价跌幅居前，业绩增长大于30%，近5日成交量回升
```

### H5. 事件 + 质量过滤

逻辑：
- 先找事件催化
- 再过滤掉垃圾票和纯题材票

**自然语言条件样例：**

```

非ST，大股东增持，资产负债率小于60%，近三年净利润为正

非ST，政策主题受益，毛利率大于25%，净利润同比增长率大于20%
```

## 如何理解复合策略

复合不是把条件越堆越多越好。

正确方式是：
- 每个条件承担不同职责
- 不重复
- 不互相打架

一个高质量复合策略通常由三层组成：

| 层级 | 作用 | 典型条件 |
|------|------|----------|
| **股票池层** | 基本面筛选 | 估值、盈利、成长、质量 |
| **验证层** | 资金面或事件面 | DDE、股东变化、业绩预增 |
| **交易层** | 技术面 | 均线、MACD、成交量 |

**示例三层结构：**
```
股票池层：PE<25，净利润增长>30%
验证层：DDE大单净量>0
交易层：股价站上20日均线
```

### 第 4 步：执行迭代

```bash
SKILL_DIR="skills/autoresearch_10jqka_backtest"
python ${SKILL_DIR}/run_iteration.py \
    --base trees/H_composite/experiments/<name> \
    --mutation-summary "【变异类型】具体改了什么（改前→改后），预期效果" \
    [--mutation-type <type>]
echo "exit: $?"
```

`--mutation-summary` 格式要求：
- 写清楚**变异类型**
- 写清楚**具体改了什么**
- 写清楚**预期效果**

`--mutation-type` 可选，不指定时系统随机选择变异类型。

**退出码含义：**
- `0` = keep（新配置更优，已保存为 champion）
- `1` = rollback（新配置不如 champion，已恢复）
- `2` = crash（执行出错，consecutive_failures +1）

## 回测参数探索

复合策略的特点：

- **持仓周期**：适中，可探索 3-8 天
- **持仓数量**：**5-12支最佳**，复合条件筛选后通常选股较少
- **止盈**：适中，可探索 20-35%
- **止损**：适中，可探索 10-15%

根据回测结果调整：
- 如果选股太少（<5支） → 放宽条件或切换分支
- 如果选股太多（>15支） → 加强复合条件
- 如果回撤太大 → 检查是否有冲突条件，调整止损
- 如果收益不稳定 → 检查三层结构是否完整

## 每次迭代要回答的标准问题

在每次变异前，问自己这几个问题：

### 逻辑问题
- 这个改动赚的到底是什么钱？是估值修复、盈利增长、资金接力，还是情绪修复？
- 这个逻辑依赖什么市场前提？

### 因子问题
- 主因子是什么？辅因子是什么？
- 哪些因子是解释逻辑的？哪些只是改善买点？

### 市场环境问题
- 牛市更有效还是熊市更有效？
- 大盘风格偏大盘时是否失效？
- 流动性收缩时是否失效？

### 风险问题
- 最大回撤可能来自什么？
- 失效时会怎么失效？是连续小亏，还是偶发大亏？

## 复合策略树特有注意事项

### 简洁性原则（核心！）

复合不等于堆砌条件。

**错误示范：**
```
PE<25 AND PB<2 AND 净利润增长>30% AND 营收增长>20% AND ROE>12% 
AND DDE>0 AND 股东户数下降 AND MACD金叉 AND 站上均线...
```
条件太多会导致：
- 选股极少，过拟合风险高
- 各条件之间可能冲突
- 无法判断哪个条件真正有效

**正确做法：**
```
股票池层（1-2个条件）：PE<25，净利润增长>30%
验证层（1个条件）：DDE>0
交易层（1个条件）：站上20日均线
```
总共 4-5 个条件，每层职责清晰。

### 条件冲突检测

避免添加互相冲突的条件，例如：
- 同时要求"低估"和"高增长"可能选不到股
- 同时要求"大跌后修复"和"均线向上"可能矛盾

### 三层结构完整性

好的复合策略应该覆盖至少两层：
- 只有股票池层 → 可能是单因子策略，不是复合策略
- 只有交易层 → 缺乏基本面支撑，风险高
- 三层都有 → 最完整，但条件不宜过多

## 评分公式（v3 - 防过拟合优化版）

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 5:
    position_penalty = (5 - maxPositions) ** 2 * 0.1
elif maxPositions > 15:
    position_penalty = (maxPositions - 15) ** 2 * 0.01
else:
    position_penalty = 0

# 过拟合惩罚（v3新增）
overfit_penalty = 持股少时胜率不足的惩罚

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15 
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty - overfit_penalty
```

**过拟合惩罚规则（v3新增）：**
持股少于5支时，胜率必须足够高：
- 持股1支：需要胜率≥60%
- 持股2支：需要胜率≥55%
- 持股3支：需要胜率≥50%
- 持股4支：需要胜率≥45%
- 持股≥5支：无限制

**选股数量建议**：5-15支最佳，避免过拟合。

**硬约束**：
- `abs(max_drawdown) > 0.35` 直接 rollback
- 新 score **严格大于** champion score 才 keep
