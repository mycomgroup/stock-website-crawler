## 质量成长树核心理念

质量成长树研究的是：**好公司能不能持续变得更好，并且这种变好能不能兑现到股价**。

这棵树不是单纯找"增长最快"的公司，而是找"增长质量高"的公司。

质量成长树最重要的判断：

- **增长是不是可持续** - 一次性增长还是长期趋势
- **增长是不是高质量** - 利润增长是否伴随现金流增长
- **当前估值有没有提前透支** - 高增长是否已被市场定价
- **市场对它的预期高不高** - 是否存在预期差

你的任务是通过回测结果，逐步找到真正有效的高质量成长策略。

## B树的五个分支

### B1. 稳定高 ROE

研究重点：
- ROE 高是短期现象，还是长期结构
- ROE 是靠净利率、周转率，还是杠杆拉起来的
- ROE 的稳定性如何

常见因子：
- ROE
- ROIC
- 净利率
- 总资产周转率
- 资产负债率

**自然语言条件样例（参考）：**

```
非ST，连续5年ROE大于15%，连续5年净利润为正，资产负债率小于60%

非ST，最近三年ROIC大于10%，毛利率连续三年大于30%，净利润率大于10%

非ST，年化ROE大于18%，总资产周转率稳定，经营活动产生的现金流量净额大于0
```

### B2. 营收与利润持续增长

这是成长树里最常见的分支。

研究重点：
- 营收增长是否真实
- 利润增长是否可持续
- 收入和利润增长是否匹配

你要重点分辨：
- 增长来自价格提升还是销量提升
- 增长来自主业还是一次性收益
- 增长来自行业扩张还是公司抢份额

**自然语言条件样例（参考）：**

```
非ST，最近8个季度营业收入同比增长率均大于20%，最近8个季度净利润同比增长率均大于20%

非ST，最近三年营业收入增长率大于15%，最近三年净利润增长率大于20%

非ST，营收增长大于30%，扣非净利润增长大于50%，营收增长小于净利润增长
```

### B3. 高毛利高净利

研究的不是"赚得多"，而是"护城河强不强"。

高毛利通常意味着：
- 品牌力
- 技术壁垒
- 行业地位
- 议价能力

研究重点：
- 毛利率是否稳定
- 净利率是否跟得上
- 是否被费用率侵蚀

**自然语言条件样例（参考）：**

```
非ST，毛利率大于40%，净利率大于15%，最近三年毛利率保持稳定

非ST，毛利率连续5年大于30%，净资产收益率大于12%，营业收入持续增长

非ST，销售净利率大于10%，毛利率高于行业中位数，经营现金流为正
```

### B4. 现金流质量成长

这是成长研究里最容易被忽略，但最重要的一枝。

研究重点：
- 净利润增长和经营现金流是否同步
- 应收账款是否快速膨胀
- 存货是否堆积
- 资本化研发、商誉、预付账款是否异常

一句话：**利润可以修饰，现金流很难伪装**。

**自然语言条件样例（参考）：**

```
非ST，最近两年经营活动产生的现金流量净额大于净利润，营收同比增长率大于15%

非ST，经营活动产生的现金流量净额连续三年为正，应收账款增长率小于营业收入增长率

非ST，货币资金减去负债总计大于1，毛利率大于30%，净利润增长率大于20%
```

### B5. 戴维斯双击

这个分支研究的是双重收益来源：
- 盈利增长
- 估值抬升

它不是简单的"成长股"，也不是简单的"价值股"，而是两者交叉：
- 估值不贵
- 增长不差
- 质量够好

这是最值得长期研究的主干之一。

**自然语言条件样例（参考）：**

```
非ST，市盈率大于0小于20，最近三个季度归属母公司股东净利润同比增长率大于20%，净利润同比增速递增

非ST，市盈率小于25，最近三年营业收入增长率大于15%，最近三年ROE大于15%

非ST，PEG小于1，净利润同比增长率大于30%，营收同比增长率大于20%
```

## 质量成长陷阱警示

在探索质量成长树时，要特别注意避免以下陷阱：

- **伪成长陷阱**：营收增长但利润不增长，或利润增长来自一次性收益
- **估值透支陷阱**：高增长已被市场充分定价，买入即透支未来收益
- **现金流陷阱**：利润增长但经营现金流恶化，增长质量低
- **高预期陷阱**：市场预期过高，即使业绩达标也会下跌

可以通过添加以下条件来规避：
- 检查利润质量（经营现金流大于净利润）
- 检查增长持续性（连续多个季度/年度增长）
- 检查估值合理性（PEG、PE等）
- 检查应收账款与存货（是否异常膨胀）

## 回测参数探索

质量成长策略的特点：

- **持仓周期**：可探索 5-10 天，成长股需要时间兑现
- **持仓数量**：**5-10支最佳**，成长股集中度可适当提高
- **止盈**：较宽，可探索 20-35%
- **止损**：适中，可探索 10-15%

根据回测结果调整：
- 如果选股太少（<5支） → 放宽ROE或增长条件
- 如果选股太多（>15支） → 加强筛选条件，提高ROE或增长率门槛
- 如果回撤太大 → 添加现金流质量条件或调整止损
- 如果收益太低 → 检查是否估值已透支，尝试戴维斯双击分支

## 每次迭代要回答的标准问题

在每次变异前，问自己这几个问题：

### 逻辑问题
- 这个改动赚的到底是什么钱？是盈利增长、估值修复，还是其他？
- 这个逻辑依赖什么市场前提？

### 因子问题
- 主因子是什么？辅因子是什么？
- 哪些因子是解释逻辑的？哪些只是改善买点？

### 市场环境问题
- 牛市更有效还是熊市更有效？
- 风险偏好上升时是否更有效？

### 风险问题
- 最大回撤可能来自什么？
- 失效时会怎么失效？是业绩不达预期，还是估值杀跌？

## 质量成长树研究常见错误（避坑）

1. **把高增长误认为高质量** - 增长快不代表增长可持续
2. **忽视现金流** - 利润增长但现金流恶化是危险信号
3. **估值透支** - 高增长已被充分定价，买入即透支
4. **忽视增长来源** - 是主业增长还是一次性收益？
5. **把策略名称当成策略逻辑** - "高ROE策略"不等于"买好公司"

## 评分公式（v3 - 防过拟合优化版）

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 5:
    position_penalty = (5 - maxPositions) ** 2 * 0.1
elif maxPositions > 15:
    position_penalty = (maxPositions - 15) ** 2 * 0.01
else:
    position_penalty = 0

# 过拟合惩罚（v3新增）
overfit_penalty = 持股少时胜率不足的惩罚

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15 
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty - overfit_penalty
```

**过拟合惩罚规则（v3新增）：**
持股少于5支时，胜率必须足够高：
- 持股1支：需要胜率≥60%
- 持股2支：需要胜率≥55%
- 持股3支：需要胜率≥50%
- 持股4支：需要胜率≥45%
- 持股≥5支：无限制

**选股数量建议**：5-15支最佳，避免过拟合。

**硬约束**：
- `abs(max_drawdown) > 0.35` 直接 rollback
- 新 score **严格大于** champion score 才 keep

## 简洁性原则

改动要权衡收益和复杂度：
- 微小提升（score 提升 < 0.001）但增加了大量复杂配置 → **不值得**
- 删掉筛选条件后得分持平或更好 → **一定 keep**
- 得分接近但配置更简洁 → **keep**
