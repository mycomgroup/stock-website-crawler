## 常用指标参考表

### 估值指标
- `pe_ttm`：市盈率（TTM）
- `pb`：市净率
- `ps`：市销率
- `pcf`：市现率

### 盈利指标
- `roe`：净资产收益率
- `roa`：总资产收益率
- `gross_profit_margin`：毛利率
- `net_profit_margin`：净利率

### 成长指标
- `revenue_growth`：营业收入增长率
- `profit_growth`：净利润增长率
- `eps_growth`：每股收益增长率

### 红利指标
- `dividend_yield`：股息率
- `dividend_payout_ratio`：分红率

### 财务质量指标
- `debt_to_equity`：资产负债率
- `current_ratio`：流动比率
- `quick_ratio`：速动比率

### 市场指标
- `turnover_rate`：换手率
- `volume`：成交量
- `market_cap`：总市值
- `circulating_market_cap`：流通市值

## JSON 生成步骤

1. **填写模板**：按照上述章节填写您的策略信息
2. **转换为 JSON**：将自然语言描述转换为 JSON 格式
3. **验证配置**：确保所有必填字段都已填写
4. **保存文件**：将 JSON 保存为 `seed_config.json`

### 转换规则

#### 筛选条件转换
```
自然语言：市盈率 < 20
JSON：{"factor": "pe_ttm", "operator": "<", "value": 20}
```

#### 排序规则转换
```
自然语言：股息率，降序，权重 0.6
JSON：{"factor": "dividend_yield", "ascending": false, "weight": 0.6}
```

#### 股票池转换
```
自然语言：沪深300
JSON："pool": "hs300"
```

## 注意事项

### 指标名称规范
- 使用英文下划线命名（如 `pe_ttm`、`dividend_yield`）
- 参考"常用指标参考表"中的标准名称
- 如需使用其他指标，请查阅 `skills/guorn_strategy/GUORN_INDICATORS_CATALOG.md`

### 权重约束
- 所有排序规则的权重总和必须为 1
- 评分权重（calmar、sortino、information_ratio）总和必须为 1

### 阈值范围
- 市盈率：通常 5-80
- 市净率：通常 0.5-5
- 净资产收益率：通常 5-30
- 股息率：通常 1-8
- 换手率：通常 0.5-10

### 持仓数量建议
- 5-10 股：高集中度，高波动
- 15-20 股：平衡配置
- 25-30 股：分散配置，低波动

### 调仓间隔建议
- 1-5 天：高频调仓，适合短期因子
- 10-15 天：中频调仓，平衡策略
- 20-30 天：低频调仓，适合长期因子

```json
{
  "name": "低估值高股息策略",
  "filters": [
    {"factor": "pe_ttm", "operator": "<", "value": 20},
    {"factor": "dividend_yield", "operator": ">", "value": 2}
  ],
  "rankings": [
    {"factor": "dividend_yield", "ascending": false, "weight": 0.6},
    {"factor": "roe", "ascending": false, "weight": 0.4}
  ],
  "pool": "hs300",
  "exclude_st": true,
  "holding_num": 15,
  "rebalance_interval": 10,
  "backtest": {
    "start": "2025-04-12",
    "end": "2026-04-12",
    "benchmark": "hs300",
    "trade_cost": 0.002
  },
  "objective": {
    "weights": {
      "calmar": 0.55,
      "sortino": 0.25,
      "information_ratio": 0.20
    },
    "hard_constraints": {
      "max_drawdown_limit": 0.35
    }
  },
  "loop": {
    "max_iterations": 100,
    "max_consecutive_failures": 5,
    "max_wait_seconds": 90
  }
}
```
