## 使用方法

### 1. 筛选策略（已完成）

```bash
node select_top_strategies.js
```

输出文件：`data/selected_top100.json`

### 2. 提交策略

```bash
# 方式1：使用专用脚本（推荐）
node batch_submit_selected.js

# 方式2：使用shell脚本
./batch_submit_top100.sh

# 自定义参数
node batch_submit_selected.js \
  --start "2025-04-03" \
  --end "2026-04-03" \
  --capital 100000 \
  --freq day \
  --sleep 5000 \
  --reuse-algorithm-id "cd45eba022e60387deb91ee6f725ef50"
```

### 3. 查看结果

提交结果保存在：`data/jq558_top100_YYYYMMDD/`

- `submissions.jsonl` - 详细日志
- `submissions.md` - 表格汇总
- `state.json` - 实时状态
- `results_snapshot.json` - 回测结果（需要单独收集）

## 资源限制说明

- 每天回测时间限制：180分钟
- 平台并发限制：最多10个回测同时运行
- 建议策略：
  - 分批提交，每批20-30个
  - 间隔时间设置为5-10秒
  - 使用 `--reuse-algorithm-id` 复用策略ID以节省创建时间
