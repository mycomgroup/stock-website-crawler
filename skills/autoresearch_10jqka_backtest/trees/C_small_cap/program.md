## 小盘风格树核心理念

小盘树研究的是：**小市值公司为什么更容易产生大收益，以及它们为什么也更容易产生大回撤**。

小盘不是一个因子，它更像一个"放大器"：

- **放大成长**：小公司在业绩改善时，弹性最大
- **放大估值修复**：小盘股关注度低，容易被错定价
- **放大情绪**：小盘股更容易受市场情绪影响
- **放大流动性风险**：小盘股更容易遭遇流动性踩踏

你的任务是通过回测结果，找到有效的小盘策略，并理解小盘"放大器"的双刃剑特性。

## C树的四个分支

### C1. 小市值价值

逻辑：小公司关注度低，容易被错定价。

适合研究的问题：
- 小盘股里哪些是真便宜
- 哪些是机构还没覆盖
- 哪些处在盈利拐点前夜

核心问题：低估值是行业共性还是公司个体问题？是短期情绪压制还是盈利会下修？

**自然语言条件样例（参考）：**

```
非ST，流通市值大于5亿元小于30亿元，市盈率大于0小于20，市净率小于1.5

非ST，总市值小于50亿元，股价小于10元，近一年净利润为正，股息率大于1.5%

非ST，小市值，动态市盈率小于行业中位数，近两年经营现金流为正
```

### C2. 小市值成长

逻辑：小公司在业绩改善时，弹性最大。

要重点研究：
- 市场空间
- 商业模式是否能复制
- 管理层执行力
- 利润率扩张能力

**自然语言条件样例（参考）：**

```
非ST，流通市值小于50亿元，营收同比增长率大于30%，净利润同比增长率大于30%

非ST，总市值小于80亿元，最近三年营业收入增长率大于20%，ROE大于10%

非ST，小市值，毛利率大于30%，净利润增长率大于50%，经营现金流为正
```

### C3. 小盘错杀

逻辑：市场恐慌、流动性收缩、风格切换时，小盘最容易被无差别抛售。

你要找的是：
- 基本面没坏
- 估值已经掉下来
- 资金面开始稳定

**自然语言条件样例（参考）：**

```
非ST，流通市值小于50亿元，近60日跌幅大于25%，净利润同比增长率大于20%

非ST，小市值，相对发行价涨跌幅小于0，营业收入同比增长率大于10%

非ST，总市值小于30亿元，近4个月股价跌幅居前，业绩增长大于30%
```

### C4. 小盘流动性与拥挤度

这是小盘研究必须单独成树的原因。

研究重点：
- 日成交额
- 换手率
- 股东结构
- 是否容易被游资操纵
- 是否容易遭遇流动性踩踏

**自然语言条件样例（参考）：**

```
非ST，流通市值大于10亿元，最近20日日均成交额大于5000万元，换手率大于2%小于10%

非ST，小市值，股东户数下降率小于-10%，近20日成交额稳定

非ST，总市值小于50亿元，近5日涨跌幅小于8%，换手率小于6%
```

## 小盘树的原则

**重要原则**：

1. **小盘不是理由，只是放大器** - 不能仅仅因为"市值小"就买入
2. **小盘必须和价值、成长、错杀、资金中的至少一项结合** - 单纯的小盘策略风险极大
3. **不要单独研究"小盘"两个字** - 小盘只是放大其他逻辑的载体

## 回测参数探索

小盘策略的特点：

- **持仓周期**：相对较短，可探索 2-5 天
- **持仓数量**：**6-12支最佳**，少于6支风险过于集中，多于12支分散收益
- **止盈**：相对较高，可探索 25-40%（小盘弹性大）
- **止损**：相对较宽，可探索 12-20%（小盘波动大）
- **移动止损**：重要，可探索 8-15%

根据回测结果调整：
- 如果选股太少（<6支） → 放宽市值上限或减少其他筛选，系统会自动惩罚
- 如果选股太多（>12支） → 加强筛选条件或降低市值上限，系统会自动惩罚
- 如果回撤太大 → 加强流动性条件或调整止损/移动止损
- 如果收益太低 → 尝试切换分支或调整止盈

## 每次迭代要回答的标准问题

在每次变异前，问自己这几个问题：

### 逻辑问题
- 这个改动赚的到底是什么钱？是成长弹性、估值修复、错杀反弹，还是其他？
- 这个逻辑依赖什么市场前提？

### 因子问题
- 主因子是什么？辅因子是什么？
- 哪些因子是解释逻辑的？哪些只是改善买点？

### 市场环境问题
- 牛市更有效还是熊市更有效？
- 小盘风格被压制时是否失效？
- 流动性收缩时是否失效？

### 风险问题
- 最大回撤可能来自什么？
- 失效时会怎么失效？是连续小亏，还是偶发大亏？

## 小盘树研究常见错误（避坑）

1. **把小盘当成买入理由** - 小盘只是放大器，不是买入逻辑
2. **忽视流动性风险** - 小盘股容易遭遇流动性踩踏
3. **忽视成长与价值的结合** - 单纯的小盘策略风险极大
4. **把高波动误认为高收益** - 小盘弹性大，但回撤也大
5. **没有设置合理的止损和移动止损** - 小盘下跌快，需要更严格的风控

## 评分公式（v2 - 防过拟合优化版）

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 6:
    position_penalty = (6 - maxPositions) ** 2 * 0.1  # 选1支扣2.5分
elif maxPositions > 12:
    position_penalty = (maxPositions - 12) ** 2 * 0.01  # 选20支扣0.64分
else:
    position_penalty = 0

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15 
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty
```

**选股数量建议**：6-12支最佳，避免风险过于集中。

**硬约束**：
- `abs(max_drawdown) > 0.35` 直接 rollback
- 新 score **严格大于** champion score 才 keep

## 简洁性原则

改动要权衡收益和复杂度：
- 微小提升（score 提升 < 0.001）但增加了大量复杂配置 → **不值得**
- 删掉筛选条件后得分持平或更好 → **一定 keep**
- 得分接近但配置更简洁 → **keep**
