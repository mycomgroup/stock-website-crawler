## 策略目标

**策略名称**: 价值树

**策略描述**: 探索估值低估带来的修复机会。核心命题：市场给这家公司定价是不是过低了。研究真便宜、周期底部便宜、质量好但暂时不受欢迎、价值陷阱四种情况。

**重要提示**: 所有优化方向必须围绕上述策略目标进行，不要偏离核心定位。

---

## 价值树核心理念

价值树研究的是一件事：**市场给这家公司定价，是不是过低了**。

价值类研究，不是在找"便宜货"这么简单，而是在分辨下面四类便宜：

- **真便宜**：估值低、盈利稳定、行业不衰退
- **周期底部便宜**：周期股在利润低点时估值看起来低，但盈利会恢复
- **质量好但暂时不受欢迎**：行业暂时不被市场偏好，但公司质量好
- **价值陷阱**：看起来便宜，实际是盈利会下修、资产质量差、行业长期衰退

你的任务是通过回测结果，逐步分辨这四类，找到真正有效的价值策略。

## A树的四个分支

### A1. 低 PE / 低 PB / 低 PS

最经典的价值分支。

- 低 PE：适合利润稳定、周期性不太强的公司
- 低 PB：适合资产型行业、金融地产、公用事业、周期底部
- 低 PS：适合利润尚未充分释放、但收入增长较强的公司

核心问题：低估值是行业共性还是公司个体问题？是短期情绪压制还是盈利会下修？

**自然语言条件样例（参考）：**

```
非ST，非退市，非停牌，动态市盈率大于0小于20，市净率小于1.5，最近一年ROE大于8%

非ST，流通市值大于10亿元，市销率低于行业中位数70%，最近两年营业收入同比增长率均大于10%

非ST，股息率大于2%，市盈率小于25，近三年净利润为正
```

### A2. 高股息 / 现金流价值

公司不仅便宜，而且能稳定把现金还给股东。

核心问题：高股息是否可持续？分红是否来自真实经营现金流？资本开支是否可控？

适合：震荡市、利率下行阶段、风险偏好不高的环境

**自然语言条件样例（参考）：**

```
非ST，近两年股息率大于3%，经营活动产生的现金流量净额大于净利润，资产负债率小于60%

非ST，近三年连续分红，自由现金流为正，市盈率小于20，股息率从大到小排序

非ST，股息率大于4%，每股经营现金流大于0.5元，近三年净利润为正
```

### A3. 深度价值 / 资产折价

不是看盈利多快，而是看安全边际够不够厚。

核心问题：总市值与净资产的关系？流动比率、速动比率？现金与资产真实可变现性？

适合：金融、地产链、资源品、重资产行业

**自然语言条件样例（参考）：**

```
非ST，市净率小于1，总市值小于净资产，流动比率大于1.5，近三年净利润为正

非ST，股价小于每股净资产，资产负债率小于50%，经营活动产生的现金流量净额大于0

非ST，市净率小于0.8，货币资金大于有息负债的50%，近两年未发生大额减值
```

### A4. 价值修复

不只是便宜，而且存在"便宜结束"的催化。

典型催化：盈利恢复、行业景气回升、政策支持、减值出清、市场重新关注

核心问题：什么会让估值中枢上移？修复需要多久？修复是不是一轮性的？

**自然语言条件样例（参考）：**

```
非ST，市盈率小于20，最近两个季度净利润同比增长率持续改善，股价近60日跌幅大于20%

非ST，市净率小于1.2，行业景气度回升，最近一个季度营收同比转正

非ST，低估值，高股息，近期无减持公告，股价站上20日均线
```

## 价值陷阱警示

在探索价值树时，要特别注意避免以下陷阱：

- **周期股陷阱**：周期股在高利润期看起来 PE 很低，但盈利会下修
- **资产质量陷阱**：资产质量差导致 PB 低但没有意义
- **行业衰退陷阱**：行业长期衰退导致"便宜越来越便宜"

可以通过添加以下条件来规避：
- 检查盈利稳定性（连续多年净利润为正）
- 检查现金流质量（经营现金流大于净利润）
- 检查行业趋势（营收增长而非下降）

### 第 4 步：执行迭代

```bash
SKILL_DIR="skills/autoresearch_10jqka_backtest"
python ${SKILL_DIR}/run_iteration.py \
    --base trees/A_value/experiments/<name> \
    --mutation-summary "【变异类型】具体改了什么（改前→改后），预期效果" \
    [--mutation-type <type>]
echo "exit: $?"
```

`--mutation-summary` 格式要求：
- 写清楚**变异类型**
- 写清楚**具体改了什么**
- 写清楚**预期效果**

`--mutation-type` 可选，不指定时系统随机选择变异类型。

**退出码含义：**
- `0` = keep（新配置更优，已保存为 champion）
- `1` = rollback（新配置不如 champion，已恢复）
- `2` = crash（执行出错，consecutive_failures +1）

## 回测参数探索

价值策略的特点：

- **持仓周期**：通常较长，可探索 5-10 天
- **持仓数量**：**5-15支最佳**，少于5支易过拟合，多于15支分散收益
- **止盈**：适中，可探索 15-25%
- **止损**：较宽，可探索 10-15%

根据回测结果调整：
- 如果选股太少（<5支） → 放宽估值条件或减少其他筛选，系统会自动惩罚
- 如果选股太多（>15支） → 加强筛选条件，系统会自动惩罚
- 如果回撤太大 → 加强安全边际条件或调整止损
- 如果收益太低 → 尝试添加修复信号或切换分支

## 每次迭代要回答的标准问题

在每次变异前，问自己这几个问题：

### 逻辑问题
- 这个改动赚的到底是什么钱？是估值修复、盈利增长，还是其他？
- 这个逻辑依赖什么市场前提？

### 因子问题
- 主因子是什么？辅因子是什么？
- 哪些因子是解释逻辑的？哪些只是改善买点？

### 市场环境问题
- 牛市更有效还是熊市更有效？
- 流动性收缩时是否失效？

### 风险问题
- 最大回撤可能来自什么？
- 失效时会怎么失效？是连续小亏，还是偶发大亏？

## 价值树研究常见错误（避坑）

1. **把低估值误认为安全** - 低估值可能是价值陷阱
2. **只看年化收益不看回撤** - 价值策略回撤可能很大
3. **把策略名称当成策略逻辑** - "低PE策略"不等于"买便宜股"
4. **把很多条件堆在一起** - 复杂不等于有效，简洁性很重要
5. **没有建立排雷层** - 先过滤ST、退市、减持公告等风险

## 评分公式（v3 - 防过拟合优化版）

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 5:
    position_penalty = (5 - maxPositions) ** 2 * 0.1
elif maxPositions > 15:
    position_penalty = (maxPositions - 15) ** 2 * 0.01
else:
    position_penalty = 0

# 过拟合惩罚（v3新增）
overfit_penalty = 持股少时胜率不足的惩罚

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15 
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty - overfit_penalty
```

**过拟合惩罚规则（v3新增）：**
持股少于5支时，胜率必须足够高：
- 持股1支：需要胜率≥60%
- 持股2支：需要胜率≥55%
- 持股3支：需要胜率≥50%
- 持股4支：需要胜率≥45%
- 持股≥5支：无限制

**选股数量建议**：5-15支最佳，避免过拟合。

**硬约束**：
- `abs(max_drawdown) > 0.35` 直接 rollback
- 新 score **严格大于** champion score 才 keep

## 简洁性原则

改动要权衡收益和复杂度：
- 微小提升（score 提升 < 0.001）但增加了大量复杂配置 → **不值得**
- 删掉筛选条件后得分持平或更好 → **一定 keep**
- 得分接近但配置更简洁 → **keep**
