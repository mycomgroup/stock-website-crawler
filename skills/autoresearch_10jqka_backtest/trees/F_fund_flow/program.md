## 资金筹码树核心理念

资金筹码树研究的是一件事：**谁在买，谁在卖，筹码是在分散还是集中**。

这棵树很有 A 股特色，因为 A 股的收益很大一部分来自：

- **筹码结构变化**：股东户数减少意味着筹码集中，散户退出、机构进入
- **增量资金偏好**：北向资金、社保、公募基金等增量资金的选股偏好
- **机构与散户行为差异**：机构通常代表"聪明钱"，散户往往追涨杀跌

资金筹码树赚的是**筹码重估的钱**——当筹码从分散到集中、从弱手到强手转移时，股价往往会有好的表现。

## F树的五个分支

### F1. 股东户数下降

**逻辑**：散户减少，筹码集中。

**研究重点**：
- 股东户数减少是否持续
- 是否伴随机构持股上升
- 是否伴随成交额稳定提升

**自然语言条件样例（参考）：**

```
非ST，股东户数报告期增长率小于-10%，机构持股占流通股比例增长值大于0

非ST，股东人数连续两个报告期下降，近20日区间涨跌幅大于0

非ST，股东户数下降，基金持股占流通股比例大于3%
```

### F2. 十大股东 / 机构持仓

**逻辑**：跟踪慢变量资金。

**研究对象**：
- 社保基金
- 高毅资产
- 公募基金
- 北向资金
- 国家队
- 牛散

**研究重点**：
- 这些持仓是新增还是存量
- 进入后表现持续多久
- 披露滞后对实盘的影响

**自然语言条件样例（参考）：**

```
非ST，前十大流通股东名称包含社保基金，前十大股东持股比例从大到小排序

非ST，前十大流通股东名称包含高毅资产，流通市值大于10亿元

非ST，国家队持股，市盈率大于0小于20，净利润增长率大于30%
```

### F3. DDE / 主力流入

**逻辑**：看短期资金行为。

**研究重点**：
- 连续性，不能只看单日
- 资金流入是否被价格确认
- 高流入后是否容易见顶

**自然语言条件样例（参考）：**

```
非ST，近3日DDE大单净量均大于0，涨跌幅小于10%，总市值小于100亿元

非ST，今日主力资金流向/流通市值从大到小排名前10，股价小于每股净值

非ST，近10日有大于2次大单净量大于0，30日均线上移
```

### F4. 融资融券与资金行为

**研究重点**：
- 融资余额变化
- 是否出现追涨行为
- 高杠杆交易是否在放大波动

**自然语言条件样例（参考）：**

```
非ST，A股融资标的，连续三个交易日融资余额增加，近三日涨跌幅大于5%

非ST，融资余额连续增加，股价站上20日均线，近5日成交量放大

非ST，融资买入额占成交额比例提升，近20日涨跌幅排名居前
```

### F5. 聪明钱跟随

**逻辑**：市场上有一部分资金的研究能力、信息处理能力、定价能力更强。

**但这里要特别注意**：
- 跟随慢变量资金，优于跟随快变量热钱
- 跟随已经披露的持仓，不能等于无脑接盘

**自然语言条件样例（参考）：**

```
非ST，前十大流通股东名称包含葛卫东，前十大股东持股比例从大到小排序

非ST，前十大流通股东名称包含科威特政府投资局，流通市值大于10亿元

非ST，社保基金持股且机构持股比例增长值大于0
```

## 筹码树最适合与什么结合

资金筹码树很少单独使用，建议与以下主树结合：

- **与价值树结合**：看便宜的票有没有人开始拿
- **与成长树结合**：看成长被谁先发现
- **与技术树结合**：看资金行为是否被趋势确认

**复合策略样例（参考）：**

```
非ST，净利润同比增长率大于30%，DDE大单净量大于0，近5日成交量放大

非ST，市盈率小于20，股东户数下降率小于-10%，机构持股比例增长值大于0

非ST，毛利率大于30%，前十大流通股东包含社保基金，近20日涨跌幅为正
```


`--mutation-summary` 格式要求：

- 写清楚**具体改了什么**

- `0` = keep（新配置更优，已保存为 champion）
- `1` = rollback（新配置不如 champion，已恢复）
- `2` = crash（执行出错，consecutive_failures +1）

## 回测参数探索

筹码策略的特点：

- **持仓周期**：中短期为主，可探索 3-8 天
- **持仓数量**：**5-10支最佳**，筹码策略通常选股范围有限
- **止盈**：适中偏紧，可探索 18-28%
- **止损**：适中，可探索 8-15%

根据回测结果调整：
- 如果选股太少（<5支）→ 放宽筹码条件或添加质量过滤条件
- 如果选股太多（>15支）→ 加强筹码集中度条件
- 如果回撤太大 → 添加质量过滤或技术确认
- 如果收益太低 → 尝试切换分支或与其他条件组合

## 资金筹码树特定注意事项

### 1. 披露滞后问题

机构持仓数据有披露滞后：
- 季报披露：季度结束后45天内
- 中报/年报：时间更长
- 这意味着看到的数据可能已经过时

**应对策略**：
- 结合短期资金流向数据（DDE、融资余额）确认当前趋势
- 关注股东户数变化趋势，而非单一点值

### 2. "聪明钱"不一定聪明

- 不是所有机构持仓都是好的
- 牛散也可能被套
- 跟随需要验证，不能无脑复制

**应对策略**：
- 添加基本面过滤（盈利、估值、现金流）
- 关注持仓变化趋势，而非静态持仓

### 3. 资金流入≠股票会涨

- 高流入后可能见顶
- 主力可能对倒
- 融资余额增加可能是追涨

**应对策略**：
- 结合估值条件避免追高
- 关注资金流入后的价格确认
- 避免单一资金信号

### 4. 筹码集中≠股价上涨

- 筹码集中可能是"锁定亏损"
- 需要基本面支撑

**应对策略**：
- 结合盈利增长条件
- 关注股价是否已有反应（避免接盘）

## 每次迭代要回答的标准问题

在每次变异前，问自己这几个问题：

### 逻辑问题
- 这个改动赚的到底是什么钱？是筹码重估、资金接力，还是其他？
- 这个逻辑依赖什么市场前提？

### 因子问题
- 主因子是什么？辅因子是什么？
- 哪些因子是解释逻辑的？哪些只是改善买点？

### 市场环境问题
- 牛市更有效还是熊市更有效？
- 大盘风格偏大盘时是否失效？
- 流动性收缩时是否失效？

### 风险问题
- 最大回撤可能来自什么？
- 失效时会怎么失效？是连续小亏，还是偶发大亏？

## 资金筹码树研究常见错误（避坑）

1. **把资金流入误认为有价值** - 资金流入可能是追涨，不等于基本面好
2. **把机构持仓当成买入信号** - 披露滞后，机构也可能被套
3. **只看单一资金信号** - 单一信号噪音大，需要多维度确认
4. **忽视披露滞后** - 季度数据可能已过时数月
5. **把"聪明钱"神话** - 机构也可能犯错，需要验证

## 评分公式（v2 - 防过拟合优化版）

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 5:
    position_penalty = (5 - maxPositions) ** 2 * 0.1  # 选1支扣1.6分
elif maxPositions > 15:
    position_penalty = (maxPositions - 15) ** 2 * 0.01  # 选50支扣1.2分
else:
    position_penalty = 0

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15 
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty
```

**选股数量建议**：5-10支最佳，避免过拟合。

**硬约束**：
- `abs(max_drawdown) > 0.35` 直接 rollback
- 新 score **严格大于** champion score 才 keep

## 简洁性原则

改动要权衡收益和复杂度：
- 微小提升（score 提升 < 0.001）但增加了大量复杂配置 → **不值得**
- 删掉筛选条件后得分持平或更好 → **一定 keep**
- 得分接近但配置更简洁 → **keep**
