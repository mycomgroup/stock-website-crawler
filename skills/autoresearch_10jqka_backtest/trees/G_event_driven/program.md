## 事件消息树核心理念

事件树研究的是一件事：**市场预期因为某个新信息发生了变化**。

事件类研究的关键不在"有事件"，而在：

- **事件是否重要**：对盈利预期的影响程度
- **事件是否超预期**：市场预期与实际结果的差异
- **事件是否能持续影响未来**：短期脉冲还是长期驱动

你的任务是通过回测结果，逐步找到真正有效的事件驱动策略。

## G树的五个分支

### G1. 业绩预增 / 扭亏

研究重点：
- 超预期幅度
- 是否连续兑现
- 市场是否已提前交易

核心问题：业绩改善是短期一次性还是可持续？市场是否已经充分预期？

**自然语言条件样例：**

```
非ST，中报预增，净利润预增上限大于50%，股价近20日涨幅小于15%

非ST，业绩扭亏，营业收入同比增长率大于20%，经营现金流转正

非ST，季报预增，扣非净利润同比增长率大于30%，市盈率小于30
```

### G2. 增持 / 回购

研究重点：
- 谁在增持
- 增持金额是否有意义
- 增持后是否真的持续买入

核心问题：增持是真实信心体现还是护盘行为？回购是否真正实施？

**自然语言条件样例：**

```
非ST，大股东增持，近3个月增持金额大于5000万元，股价近20日跌幅大于10%

非ST，董监高增持，净利润同比增长率大于20%，资产负债率小于60%

非ST，回购预案，回购金额占总市值比例较高，市盈率小于25
```

### G3. 高送转 / 分红

研究重点：
- 是真实股东回报，还是题材炒作
- 是否叠加业绩支持

核心问题：分红是否可持续？高送转是否有基本面支撑？

**自然语言条件样例：**

```
非ST，近两年股息率大于2%，每股未分配利润大于2元，每股公积金大于3元

非ST，高送转预案，净资产收益率大于10%，总股本小于3亿股

非ST，分红率提升，经营现金流量净额为正，近三年净利润为正
```

### G4. 政策 / 主题催化

研究重点：
- 政策是口号还是落地
- 板块是一日游还是中期主线
- 哪些公司是真受益，哪些只是蹭概念

核心问题：政策影响的持续性和深度？公司是否真正受益？

**自然语言条件样例：**

```
非ST，所属同花顺行业是铁路或农业或医疗或金融或医药，近20日涨跌幅从小到大排序

非ST，华为概念，国企，最近一个季度净利润同比增长率大于20%

非ST，5G行业，大股东增持，近一年营业收入同比增长率为正
```

### G5. 研报目标价与预期差

研究重点：
- 市场预期和卖方预期差多大
- 目标价是否被基本面支撑
- 是否存在一致性过高的问题

核心问题：目标价是否合理？预期差是否已被市场消化？

**自然语言条件样例：**

```
非ST，股价/目标价小于0.7，低估值，高增长

非ST，近30日涨幅较小，目标价上行空间大于30%，净利润同比增长率为正

非ST，研报强烈推荐，市盈率低于行业中位数，近一个季度业绩超预期
```

## 事件树最大难点

事件驱动策略的三大难点：

### 1. 噪音太大

- 每天都有大量公告和消息
- 大部分事件对股价影响微弱
- 需要筛选出真正重要的事件

**应对策略**：
- 添加基本面质量过滤
- 检查事件是否超预期
- 避免纯概念炒作

### 2. 持续性难判断

- 事件是一次性脉冲还是趋势起点？
- 市场是否已经提前交易？
- 后续是否有验证？

**应对策略**：
- 检查是否有连续事件确认
- 添加业绩改善趋势条件
- 观察资金面是否配合

### 3. 容易被情绪裹挟

- 追热点、追概念
- 忽视估值和风险
- 高位接盘

**应对策略**：
- 添加估值保护条件
- 添加价格保护条件（如近期涨幅限制）
- 结合基本面质量过滤

**核心建议**：事件树最好只作为**催化增强器**和**研究线索来源**，而不是唯一买入理由。必须结合价值、成长、资金等维度。

## 事件消息树特定注意事项

### 1. 事件时效性

事件驱动策略时效性强，要注意：
- 业绩预增公告后市场反应时间窗口
- 增持/回购公告后实施进度
- 政策主题的持续性

### 2. 避免追高

事件股容易短期大涨，要添加保护：
- `股价近20日涨幅小于X%`（如15-20%）
- 避免在市场情绪高点买入

### 3. 结合基本面

纯事件驱动风险高，建议添加：
- 估值保护：`市盈率小于X`
- 盈利质量：`净利润同比增长率为正`
- 现金流：`经营活动产生的现金流量净额大于0`

### 4. 分支切换策略

当某分支效果不佳时：
- 检查是否市场环境不适合（如业绩期、政策空窗期）
- 尝试切换到其他分支
- 考虑与其他树（如价值树、资金树）结合

## 回测参数探索

事件驱动策略的特点：

- **持仓周期**：通常较短，2-5天为宜
- **持仓数量**：**5-10支最佳**，事件股数量通常有限
- **止盈**：较激进，可探索 20-35%
- **止损**：适中，可探索 10-15%

根据回测结果调整：
- 如果选股太少（<3支） → 放宽事件条件或添加辅助筛选
- 如果事件失效太快 → 缩短持仓周期或调整止盈止损
- 如果回撤太大 → 加强基本面质量过滤

## 每次迭代要回答的标准问题

在每次变异前，问自己这几个问题：

### 逻辑问题
- 这个事件是否真正重要？市场预期变化多少？
- 这个事件的影响是短期的还是可持续的？

### 因子问题
- 事件条件是什么？辅助筛选条件是什么？
- 是否添加了防止追高的保护？

### 市场环境问题
- 当前是业绩期还是非业绩期？
- 政策主题是主线还是支线？

### 风险问题
- 事件是否已被市场提前消化？
- 是否存在"见光死"风险？

## 事件树研究常见错误（避坑）

1. **把事件名称当成策略逻辑** - "业绩预增"不等于"买预增股"
2. **忽视事件是否超预期** - 预期内的预增没有超额收益
3. **追热点追概念** - 忽视基本面和估值
4. **忽视时效性** - 事件公告后反应窗口很短
5. **没有添加价格保护** - 高位买入事件股风险极大

## 评分公式（v3 - 防过拟合优化版）

```
calmar = annual_return / max(abs(max_drawdown), 0.01)
complexity_penalty = min((formula条件数 + 调优参数数) / 10, 1.0)

# 选股数量惩罚（双边软约束）
if maxPositions < 5:
    position_penalty = (5 - maxPositions) ** 2 * 0.1
elif maxPositions > 15:
    position_penalty = (maxPositions - 15) ** 2 * 0.01
else:
    position_penalty = 0

# 过拟合惩罚（v3新增）
overfit_penalty = 持股少时胜率不足的惩罚

score = sortino * 0.40 + calmar * 0.25 + information_ratio * 0.15 
      + win_rate * 0.10 - complexity_penalty * 0.10 - position_penalty - overfit_penalty
```

**过拟合惩罚规则（v3新增）：**
持股少于5支时，胜率必须足够高：
- 持股1支：需要胜率≥60%
- 持股2支：需要胜率≥55%
- 持股3支：需要胜率≥50%
- 持股4支：需要胜率≥45%
- 持股≥5支：无限制

**选股数量建议**：5-15支最佳，避免过拟合。

**硬约束**：
- `abs(max_drawdown) > 0.35` 直接 rollback
- 新 score **严格大于** champion score 才 keep

## 简洁性原则

改动要权衡收益和复杂度：
- 微小提升（score 提升 < 0.001）但增加了大量复杂配置 → **不值得**
- 删掉筛选条件后得分持平或更好 → **一定 keep**
- 得分接近但配置更简洁 → **keep**
