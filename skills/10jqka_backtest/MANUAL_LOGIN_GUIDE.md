# 问财公式回测 - 手动登录指南

## 为什么需要手动登录？
直接使用同花顺 `quant.10jqka.com.cn`（代码量化回测）的鉴权 Cookies，经常会在问财 `backtest.10jqka.com.cn` 服务器报错提示 `-401 noauth`。问财的回测模块由于面向不同业务且采用了独立的用户校验链路，有严格的登录与状态跟踪拦截。

为了能在机器端平滑运行自动化接口请求，请按照以下步骤生成或续期会话信息。

## 登录完整步骤

### 1. 运行捕获脚本
在此目录下执行:
```bash
npm install
node browser/manual-login-capture.js
```

### 2. 在自动弹出的浏览器中手动登录
- 脚本会为你打开一个带有可视化界面的 Chromium 浏览器，并导航到问财回测核心界面（如 `https://backtest.10jqka.com.cn/backtest/app.html#/strategybacktest`）。
- **请务必不要关闭弹出页**，在页面上点击登录窗口并手动完成扫码或者账号密码+滑块验证。

### 3. 生成有效测试请求（关键一步）
为了确认您的登录 Token 已经完全颁发给了全量接口分支，在看到登录成功之后的 "问财界面" 后：
1. 随便输入一行简单的问财自然语言查询，比如: `创业板，非ST，跌停`
2. 点击页面大红色的 **"开始回测"**（或类似启动按钮）
3. 代码将在后台侦听 `yieldbacktest` 核心请求的出入报文，当检测到 200 HTTP 且返回值内无 `-401` 时，脚本会在终端打印已完成捕获。

### 4. 自动保存并关闭
当控制台提示 `✅ Session已保存至:` 时，代表提取已完成。
这之后浏览器页面会在两分钟倒计时结束后自动安全退出（或者你可以直接停止 Node 进程），Cookie 已被写入到 `data/session.json` 当中。

## 其他说明
- 该登录状态通常具有 7天 或以上的有效期，请在此有效期内复用。如果终端报 `-401`，则代表需要回来重新运行一次上述采集流程。
- 如果在运行时碰见无相关浏览器的错误：请先安装浏览器组件依赖，如使用 `npx playwright install` 初始化系统配置。
