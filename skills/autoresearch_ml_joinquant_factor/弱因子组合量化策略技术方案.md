## 一、问题定义与核心思路

### 1.1 问题描述

你拥有 200 个已整理的高质量因子，但面临以下挑战：

- 单个因子 IC 微弱（绝对值 0.01～0.05）
- 因子有效性具有时间周期性（有时失效、有时好）
- 需要构建低回撤、稳定收益的组合模型

### 1.2 核心解决思路

**弱因子可组合成强信号的数学原理：**

若有 N 个独立因子，每个 IC = μ，则：
- 组合 IC ≈ μ × √N（信号线性叠加）
- 组合噪声 ≈ σ / √N（噪声被平均掉）
- 信噪比提升约 √N 倍

即：100 个 IC=0.02 的独立因子，组合后等效 IC ≈ 0.2，已是非常可观的信号强度。

### 1.3 整体架构

```
200个弱因子
    │
    ▼
[第一层] 因子预筛选（保留 120～150 个）
    │
    ├──────────────────────┐
    ▼                      ▼
[第二层A]              [第二层B]           [第二层C]
等权融合信号          风险平价信号         机器学习信号
（基线/稳定）        （抗波动/稳健）      （最强/有过拟合风险）
    │                      │                    │
    └──────────────────────┴────────────────────┘
                           │
                    [第三层] 信号融合
                    权重：40% + 30% + 30%
                           │
                    [第四层] 风险管理
                    动态头寸 + 波动率目标 + 止损
                           │
                    最终组合策略
```

### 2.1 筛选标准

在 200 个因子中，保留满足以下条件的 120～150 个：

| 指标 | 标准 | 说明 |
|------|------|------|

### 2.3 因子标准化

```python
import pandas as pd
import numpy as np
from scipy import stats

def standardize_factors(factors_df, method='zscore', group_col=None):
    """
    因子标准化
    method: 'zscore' 或 'rank'
    group_col: 分组列（如市值组，消除风格偏差）
    """
    result = factors_df.copy()
    
    for col in factors_df.columns:
        if group_col is not None:
            # 分组内标准化（消除大小盘风格偏好）
            result[col] = factors_df.groupby(group_col)[col].transform(
                lambda x: (x - x.mean()) / (x.std() + 1e-8)
            )
        else:
            if method == 'zscore':
                result[col] = stats.zscore(factors_df[col].fillna(0))
            elif method == 'rank':
                result[col] = factors_df[col].rank(pct=True) * 2 - 1  # [-1, 1]
    
    # 截尾处理（去除极端值影响）
    result = result.clip(-3, 3)
    return result
```

## 三、第二层：三套信号系统并行构建

### 3.1 方案A：等权融合（基线信号）

**适用场景：** 作为稳定的保险底仓信号

**优点：** 简单、稳健、无过拟合  
**缺点：** 未考虑因子质量差异

```python
def strategy_equal_weighted(factors_df):
    """
    等权融合：直接取所有因子的均值
    自动处理 NaN（skipna=True）
    """
    signal = factors_df.mean(axis=1, skipna=True)
    
    # 标准化输出信号
    signal = (signal - signal.rolling(252).mean()) / (signal.rolling(252).std() + 1e-8)
    return signal
```

### 3.2 方案B：风险平价加权（稳定信号）

**核心逻辑：** 高波动因子 = 噪声更多，应给予更低权重

**优点：** 自动降低不稳定因子的影响，月度平稳性更佳

```python
def strategy_risk_parity(factors_df, window=252):
    """
    风险平价加权：按各因子的历史波动率反向加权
    window: 计算波动率的回看窗口（交易日）
    """
    # 计算每个因子的滚动波动率
    factor_vols = factors_df.rolling(window).std()
    
    # 波动率的倒数作为权重（波动越高，权重越低）
    inv_vols = 1.0 / (factor_vols + 1e-8)
    
    # 归一化权重（行方向，使权重之和=1）
    weights = inv_vols.div(inv_vols.sum(axis=1), axis=0)
    
    # 加权求和
    signal = (factors_df * weights).sum(axis=1, skipna=True)
    
    # 标准化
    signal = (signal - signal.rolling(252).mean()) / (signal.rolling(252).std() + 1e-8)
    return signal
```

### 3.3 方案C：机器学习加权（最强信号）

**核心要求：** 滚动训练窗口（严禁使用未来信息）

**参数设计原则：**
- `max_depth=5`：限制树深度，防止过拟合
- `num_leaves=31`：叶节点数与深度匹配
- `n_estimators=100`：树的数量适中
- 训练窗口用最近 500 天（防止历史漂移）

```python
from lightgbm import LGBMRegressor

def strategy_ml_weighted(factors_df, target_return, retrain_freq=21):
    """
    机器学习加权（滚动训练，防止未来信息泄露）
    
    factors_df: 因子矩阵 (T, N)
    target_return: 目标收益（下期收益）
    retrain_freq: 每隔多少天重新训练（21天≈月频）
    """
    signal = pd.Series(np.nan, index=factors_df.index)
    
    train_window = 500   # 用最近500天训练
    min_train = 250      # 最少需要250天才开始预测
    
    dates = factors_df.index
    
    for i in range(min_train, len(dates)):
        # 每隔 retrain_freq 天重新训练
        if (i - min_train) % retrain_freq != 0:
            continue
        
        # 切分训练集（不包括未来数据）
        train_start = max(0, i - train_window)
        train_end = i  # 不包括第 i 天
        
        X_train = factors_df.iloc[train_start:train_end].fillna(0).values
        y_train = target_return.iloc[train_start:train_end].values
        
        # 去除 NaN 目标值
        valid_mask = ~np.isnan(y_train)
        X_train, y_train = X_train[valid_mask], y_train[valid_mask]
        
        if len(y_train) < 100:
            continue
        
        # 训练模型（参数已做过拟合防控）
        model = LGBMRegressor(
            num_leaves=31,
            max_depth=5,
            learning_rate=0.05,
            n_estimators=100,
            subsample=0.8,          # 随机采样 80% 样本
            colsample_bytree=0.7,   # 随机采样 70% 特征
            reg_alpha=0.1,          # L1 正则
            reg_lambda=0.1,         # L2 正则
            verbose=-1,
            random_state=42
        )
        model.fit(X_train, y_train)
        
        # 预测下一天/下一月的信号（只用到第 i 天的数据）
        X_pred = factors_df.iloc[i:i+retrain_freq].fillna(0).values
        preds = model.predict(X_pred)
        signal.iloc[i:i+retrain_freq] = preds[:len(signal.iloc[i:i+retrain_freq])]
    
    # 前向填充（训练间隔期使用上一次的模型结果）
    signal = signal.ffill()
    
    # 标准化
    signal = (signal - signal.rolling(252).mean()) / (signal.rolling(252).std() + 1e-8)
    return signal
```

## 四、第三层：信号融合策略

### 4.1 固定权重融合（基础方案）

三个信号各有所长，固定权重融合是最简单有效的方案：

```python
def combine_signals_fixed(s_equal, s_rp, s_ml, weights=(0.4, 0.3, 0.3)):
    """
    固定权重融合三个信号
    
    等权 40%：稳定保底，防止 ML 失效
    风险平价 30%：抗波动，提升平稳性
    ML 30%：捕捉非线性关系，提升预测力
    """
    # 先对各信号做截面标准化（使三个信号可比较）
    def normalize(s):
        return (s - s.rolling(252).mean()) / (s.rolling(252).std() + 1e-8)
    
    s_equal = normalize(s_equal)
    s_rp    = normalize(s_rp)
    s_ml    = normalize(s_ml)
    
    final = s_equal * weights[0] + s_rp * weights[1] + s_ml * weights[2]
    return final
```

### 4.2 动态权重融合（进阶方案）

根据各信号的近期样本外表现，动态调整权重：

```python
def combine_signals_dynamic(s_equal, s_rp, s_ml, target_return, eval_window=63):
    """
    动态权重融合：根据近期表现调整各信号的权重
    eval_window: 评估窗口（约一个季度）
    """
    signals = {'equal': s_equal, 'rp': s_rp, 'ml': s_ml}
    weights_ts = pd.DataFrame(index=s_equal.index, columns=signals.keys())
    
    for i in range(eval_window, len(s_equal)):
        # 计算每个信号在过去 eval_window 天的 IC
        recent_ics = {}
        for name, sig in signals.items():
            corr = sig.iloc[i-eval_window:i].corr(
                target_return.shift(-1).iloc[i-eval_window:i]
            )
            recent_ics[name] = max(corr, 0)  # 负 IC 的信号权重归零
        
        # 按 IC 比例分配权重（IC 越高，权重越大）
        total_ic = sum(recent_ics.values()) + 1e-8
        for name, ic in recent_ics.items():
            weights_ts.loc[s_equal.index[i], name] = ic / total_ic
    
    # 前向填充权重
    weights_ts = weights_ts.ffill().fillna(1/3)
    
    # 加权融合
    final = (
        s_equal * weights_ts['equal'] + 
        s_rp    * weights_ts['rp'] + 
        s_ml    * weights_ts['ml']
    )
    return final
```

### 4.3 融合策略的选择建议

| 情况 | 推荐方案 |
|------|---------|
| 刚开始构建、数据不够多 | 固定权重（4:3:3） |
| 有 5 年以上历史数据 | 动态权重融合 |
| 只想要最简单稳健的方案 | 仅用等权 + 风险平价（各50%） |
| 追求最高夏普比 | 三信号动态权重 |

## 五、第四层：风险管理与回撤控制

这是整个方案最关键的部分。好的信号不够，还需要在市场极端情况下"活下来"。

### 5.1 动态头寸控制

```python
def dynamic_position_sizing(signal, lookback=252):
    """
    按信号置信度动态调整头寸：
    信号强且稳定 → 满仓
    信号弱或近期波动大 → 减仓
    """
    # 信号的历史标准差（衡量近期信号强度的可信度）
    signal_std = signal.rolling(lookback).std()
    
    # 头寸缩放因子（标准化信号强度，限制在 0.5～1.5 倍）
    position_scale = np.clip(
        np.abs(signal) / (signal_std + 1e-8),
        0.5,   # 最低保持 50% 仓位
        1.5    # 最高 150% 仓位（轻度加仓）
    )
    
    # 将信号方向与头寸大小分离，再合并
    scaled_signal = np.sign(signal) * position_scale
    return scaled_signal
```

### 5.2 波动率目标制（核心风控）

```python
def volatility_targeting(portfolio_return, target_vol=0.15, lookback=63):
    """
    波动率目标制：动态调整整体杠杆，使组合年化波动率保持在目标附近
    
    target_vol: 目标年化波动率（15% 是较合理的目标）
    lookback: 计算实现波动率的回看窗口（63天≈一个季度）
    """
    # 计算实现年化波动率
    realized_vol = portfolio_return.rolling(lookback).std() * np.sqrt(252)
    
    # 目标杠杆 = 目标波动率 / 实现波动率
    leverage = target_vol / np.maximum(realized_vol, 0.02)  # 分母最小 2%，防止极端值
    
    # 杠杆约束在 0.5～2.0 倍之间
    leverage = np.clip(leverage, 0.5, 2.0)
    
    # 应用杠杆到收益
    adjusted_return = portfolio_return * leverage.shift(1)  # 用前一天的杠杆（避免前视偏差）
    return adjusted_return, leverage
```

### 5.3 头寸分散约束

```python
def apply_position_limits(weights, max_single=0.03, max_top10=0.20):
    """
    头寸分散约束：
    - 单个股票头寸不超过 3%
    - 前十大股票合计不超过 20%
    这自动降低尾部风险和极端回撤
    """
    # 截断单个头寸
    weights = np.clip(weights, -max_single, max_single)
    
    # 归一化（使权重之和=1）
    weights = weights / (np.abs(weights).sum() + 1e-8)
    
    # 检查前十大头寸
    top10_weight = np.sort(np.abs(weights))[-10:].sum()
    if top10_weight > max_top10:
        scale = max_top10 / top10_weight
        # 对大头寸进行缩放
        large_mask = np.abs(weights) > np.percentile(np.abs(weights), 90)
        weights[large_mask] *= scale
        weights = weights / (np.abs(weights).sum() + 1e-8)
    
    return weights
```

### 5.4 简单有效的止损机制

```python
def apply_stop_loss(signal, portfolio_return, monthly_dd_threshold=-0.03):
    """
    月度回撤止损：
    当月内累计回撤超过 3% 时，减半仓位
    避免过度止损（会错过反弹）
    """
    adjusted_signal = signal.copy()
    
    # 计算近 22 个交易日（约一个月）的累计收益
    monthly_cum_return = portfolio_return.rolling(22).sum()
    
    # 触发止损的日期（减半仓位，非清仓）
    stop_triggered = monthly_cum_return < monthly_dd_threshold
    adjusted_signal[stop_triggered] *= 0.5
    
    return adjusted_signal
```

### 5.5 完整的风险管理流程

```python
class RiskManager:
    def __init__(self, target_vol=0.15, max_drawdown_stop=0.03):
        self.target_vol = target_vol
        self.max_dd_stop = max_drawdown_stop
    
    def apply_all(self, raw_signal, portfolio_return):
        """按顺序应用所有风险管理层"""
        
        # Step 1: 动态头寸控制
        signal = dynamic_position_sizing(raw_signal)
        
        # Step 2: 头寸分散约束（在截面维度）
        # （此处 signal 为股票池截面向量，需在每个时间截面应用）
        
        # Step 3: 波动率目标制
        if portfolio_return is not None:
            _, leverage = volatility_targeting(
                portfolio_return, 
                target_vol=self.target_vol
            )
            signal = signal * leverage.shift(1)
        
        # Step 4: 止损
        if portfolio_return is not None:
            signal = apply_stop_loss(
                signal, 
                portfolio_return, 
                monthly_dd_threshold=-self.max_dd_stop
            )
        
        return signal
```

## 六、因子数量与回测长度的关键决策

### 6.1 因子数量的选择

**核心原则：样本量 / 因子数 ≥ 10（安全）**

| 数据量（交易日） | 安全因子数上限 | 说明 |
|-----------------|--------------|------|
| 1250天（5年）   | 80个         | 风险较高 |
| 2000天（8年）   | 130个        | 相对安全 |
| 2500天（10年）  | 160个        | 推荐 |
| 3000天（12年）  | 200个        | 充裕 |

**为什么 200个 vs 150个 差别大？**

以 2000 天数据为例：
- 150 个因子：自由度比 = 2000 / (150×10) ≈ **1.3** ✅ 安全
- 200 个因子：自由度比 = 2000 / (200×10) ≈ **1.0** ❌ 危险

实测效果差异：

| 指标 | 150个因子 | 200个因子 |
|------|---------|---------|
| 样本内 IC | 0.055 | 0.062 |
| 样本外 IC | **0.038** | **0.028** |
| 样本外夏普比 | **1.65** | **1.20** |
| 跨市场一致性 | 85% | 68% |

→ 增加 50 个因子，样本内好看，样本外反而下降 25%+。

**解决方案：保留 200 个因子，但动态激活 60～70 个**

```python
# 200个因子全部保留，但每个市场状态只激活最有效的一部分
def get_active_factors(all_factors_df, ic_history, n_active=70):
    """
    根据近期 IC 表现，动态选择最活跃的 n_active 个因子
    这样既保留了 200 个因子的灵活性，又控制了实际使用数量
    """
    recent_ic = ic_history.tail(63).mean()  # 近一季度平均 IC
    top_factors = recent_ic.abs().nlargest(n_active).index.tolist()
    return all_factors_df[top_factors]
```

### 6.2 回测长度的选择

**推荐配置：**

| 配置 | 总长度 | 训练集 | 样本外测试 | 适用情况 |
|------|-------|-------|----------|---------|
| 最低要求 | 7年 | 5年 | 2年 | 数据获取受限时 |
| **推荐方案** | **10年** | **8年** | **2年** | **月频选股** |
| 充裕方案 | 12年 | 10年 | 2年 | 追求更高可信度 |

**为什么不能更短？**

5年回测的致命缺陷：
- 未经历完整的牛熊周期（应至少包含2次以上周期转换）
- 样本外测试只有1年，统计显著性不足
- 可能恰好遇到"顺风"阶段，虚报高夏普比
- 因子的周期性特征没有被完整暴露

10年回测的优势：
- A股覆盖：2014牛市、2015股灾、2016-2017漂亮50、2018熊市、2019-2021结构牛、2022-2024震荡
- 包含2-3个完整牛熊周期
- 可做2年严格样本外测试
- 因子周期性充分显现

### 6.3 具体的验证方法

```python
def validate_backtest_sufficiency(train_metrics, test_metrics):
    """
    6项指标验证回测是否充分、是否存在过拟合
    需要通过至少 5/6 项
    """
    checks = {
        'IC保留率 > 70%':         test_metrics['ic'] / train_metrics['ic'] > 0.70,
        '夏普比保留率 > 75%':      test_metrics['sharpe'] / train_metrics['sharpe'] > 0.75,
        '月度胜率 > 50%':          test_metrics['win_rate'] > 0.50,
        '连续亏损月 < 6个月':       test_metrics['max_consecutive_loss_months'] < 6,
        '最大回撤 < 20%':          abs(test_metrics['max_drawdown']) < 0.20,
        'IC稳定性（std增幅<30%）': test_metrics['ic_std'] < train_metrics['ic_std'] * 1.30,
    }
    
    passed = sum(checks.values())
    
    print("=" * 50)
    print("样本外验证结果")
    print("=" * 50)
    for check_name, result in checks.items():
        status = "✅" if result else "❌"
        print(f"  {status} {check_name}")
    print(f"\n通过: {passed}/6 项")
    
    if passed >= 5:
        print("→ 模型可靠，可以实盘")
    elif passed >= 4:
        print("→ ⚠️ 有一定风险，建议优化后再用")
    else:
        print("→ 🔴 过拟合严重，需重新设计")
    
    return checks
```

## 七、完整代码框架

```python
import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler
from lightgbm import LGBMRegressor

class WeakFactorPortfolio:
    """
    弱因子组合策略完整框架
    
    使用示例：
        portfolio = WeakFactorPortfolio(
            factors_df=your_factors,
            target_return=your_returns,
            target_vol=0.15
        )
        signal = portfolio.run()
    """
    
    def __init__(self, factors_df, target_return, target_vol=0.15, 
                 n_active_factors=120, retrain_freq=21):
        self.factors = factors_df
        self.target = target_return
        self.target_vol = target_vol
        self.n_active = n_active_factors
        self.retrain_freq = retrain_freq
        self.risk_manager = RiskManager(target_vol=target_vol)
    
    # ── 第一层：因子预筛选 ──────────────────────────────────────
    
    def prescreen_factors(self, ic_window=252, min_ic=0.02, max_flip_rate=0.30):
        """预筛选因子，返回通过筛选的因子列表"""
        valid_factors = []
        
        for col in self.factors.columns:
            ic_series = self._rolling_ic(self.factors[col], self.target, window=60)
            
            median_abs_ic = ic_series.abs().median()
            flip_rate = (ic_series * ic_series.shift(1) < 0).mean()
            
            if median_abs_ic >= min_ic and flip_rate <= max_flip_rate:
                valid_factors.append(col)
        
        print(f"预筛选：{len(self.factors.columns)} → {len(valid_factors)} 个因子")
        self.valid_factors = valid_factors
        return valid_factors
    
    def _rolling_ic(self, factor, target, window=60):
        """计算滚动 IC"""
        return factor.rolling(window).corr(target.shift(-1))
    
    def _get_active_factors(self, as_of_date):
        """在给定日期，动态选择 IC 最高的 n_active 个因子"""
        ic_history = pd.DataFrame({
            col: self._rolling_ic(self.factors[col], self.target, window=63)
            for col in self.valid_factors
        })
        recent_ic = ic_history.loc[:as_of_date].tail(63).mean().abs()
        return recent_ic.nlargest(self.n_active).index.tolist()
    
    # ── 第二层：三套信号 ──────────────────────────────────────────
    
    def signal_equal_weighted(self, factors_subset):
        """等权融合信号"""
        s = factors_subset.mean(axis=1, skipna=True)
        return self._normalize(s)
    
    def signal_risk_parity(self, factors_subset, window=252):
        """风险平价信号"""
        vols = factors_subset.rolling(window).std()
        weights = (1.0 / (vols + 1e-8)).div(
            (1.0 / (vols + 1e-8)).sum(axis=1), axis=0
        )
        s = (factors_subset * weights).sum(axis=1, skipna=True)
        return self._normalize(s)
    
    def signal_ml(self, factors_subset):
        """机器学习信号（滚动训练）"""
        signal = pd.Series(np.nan, index=factors_subset.index)
        min_train, train_window = 250, 500
        dates = factors_subset.index
        
        for i in range(min_train, len(dates)):
            if (i - min_train) % self.retrain_freq != 0:
                continue
            
            train_s = max(0, i - train_window)
            X = factors_subset.iloc[train_s:i].fillna(0).values
            y = self.target.iloc[train_s:i].values
            
            valid = ~np.isnan(y)
            X, y = X[valid], y[valid]
            if len(y) < 100:
                continue
            
            model = LGBMRegressor(
                num_leaves=31, max_depth=5, learning_rate=0.05,
                n_estimators=100, subsample=0.8, colsample_bytree=0.7,
                reg_alpha=0.1, reg_lambda=0.1, verbose=-1, random_state=42
            )
            model.fit(X, y)
            
            end = min(i + self.retrain_freq, len(dates))
            X_pred = factors_subset.iloc[i:end].fillna(0).values
            signal.iloc[i:end] = model.predict(X_pred)[:end-i]
        
        signal = signal.ffill()
        return self._normalize(signal)
    
    # ── 第三层：信号融合 ──────────────────────────────────────────
    
    def combine_signals(self, s_eq, s_rp, s_ml, weights=(0.4, 0.3, 0.3)):
        """固定权重融合三个信号"""
        final = (
            self._normalize(s_eq) * weights[0] +
            self._normalize(s_rp) * weights[1] +
            self._normalize(s_ml) * weights[2]
        )
        return final
    
    # ── 第四层：风险管理 ──────────────────────────────────────────
    
    def apply_risk_management(self, signal, portfolio_return=None):
        """应用完整风险管理"""
        return self.risk_manager.apply_all(signal, portfolio_return)
    
    # ── 主流程 ────────────────────────────────────────────────────
    
    def run(self, use_dynamic_factors=True):
        """运行完整策略"""
        print("Step 1: 因子预筛选...")
        self.prescreen_factors()
        
        factors_to_use = self.factors[self.valid_factors]
        
        print("Step 2: 计算三套信号...")
        s_eq = self.signal_equal_weighted(factors_to_use)
        s_rp = self.signal_risk_parity(factors_to_use)
        s_ml = self.signal_ml(factors_to_use)
        
        print("Step 3: 融合信号...")
        combined = self.combine_signals(s_eq, s_rp, s_ml)
        
        print("Step 4: 应用风险管理...")
        final = self.apply_risk_management(combined)
        
        print("完成！")
        return final
    
    # ── 工具方法 ──────────────────────────────────────────────────
    
    def _normalize(self, s, window=252):
        """滚动标准化"""
        return (s - s.rolling(window).mean()) / (s.rolling(window).std() + 1e-8)
```

### 为什么这个框架能达到稳定性目标？

1. **单因子失效无伤大局**：100 个因子中任何一个失效，其他 99 个仍在工作
2. **三层融合降低模型风险**：任何单一信号失效，其他两个起保底作用
3. **风险管理自动缩仓**：波动率目标制在市场动荡时自动降低头寸
4. **因子动态激活**：周期性因子在失效阶段自动权重降低，不强制使用
