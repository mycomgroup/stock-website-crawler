# 通用机制库 (Universal Mechanisms)

> **定位**：从 200+ 个 A 股策略中提炼的可复用机制，按策略层次分类，重点机制提供多种实现变体。
> **使用方式**：autoresearch 改动前先查本文档，优先从已验证机制中选方向，而不是随机试错。

---

## 一、机制全景图（按策略层次）

```
策略执行流
├── L0 基础过滤层      ← 所有策略必须有，否则回测失真
├── L1 选股/Alpha层    ← 核心收益来源
├── L2 择时/门控层     ← 控制入场时机，降低回撤
├── L3 仓位管理层      ← 控制每笔风险敞口
├── L4 风控/退出层     ← 止损止盈，防止单次大亏
├── L5 组合优化层      ← 多标的权重分配
└── L6 流程规范层      ← 验证、归因、准入标准
```

## 三、重点机制多实现对照

### 择时机制对比（同一策略加不同择时）

| 择时方式 | 原理 | 适合策略类型 | 典型效果 |
|---------|------|------------|---------|
| 情绪开关（涨停家数） | 市场情绪代理 | 小市值/首板/短线 | 回撤 -30~40% |
| RSRS | 支撑阻力强度 | ETF轮动/趋势 | 年化 +20~50% |
| 扩散指数双均线 | 全市场上涨占比 | 微盘/小市值 | 回撤 -38% |
| 布林带 | 价格通道突破 | 趋势/ETF | 减少假突破 |
| 北向资金 | 外资流向 | 大盘蓝筹 | 超额 +10~20% |
| FED估值 | 宏观估值顶底 | 长线/价值 | 规避大熊市 |

### 仓位管理对比

| 方式 | 复杂度 | 适合场景 | 典型效果 |
|------|--------|---------|---------|
| 等权 | 低 | 基准/快速验证 | — |
| 波动率加权 | 中 | 多标的组合 | 夏普 +15% |

### 退出规则对比

| 方式 | 触发条件 | 适合场景 | 注意事项 |
|------|---------|---------|---------|
| 固定止损 | 亏损 > X% | 短线/事件驱动 | 容易被洗出 |
