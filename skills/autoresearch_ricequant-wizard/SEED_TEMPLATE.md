## 筛选条件（Filters）

列出所有筛选条件，每个条件包含：因子名称、操作符、阈值

**操作符**：
- `greater_than` - 大于
- `less_than` - 小于
- `in_range` - 在范围内

示例：
1. 市盈率 < 20
2. 股息率 > 2
3. 净资产收益率 > 10

**您的筛选条件**：
1. [因子名称] [操作符] [阈值]
2. [因子名称] [操作符] [阈值]
3. ...

---

## 排序规则（Sorting）

列出排序规则，每个规则包含：因子名称、排序方向、权重

**排序方向**：
- `ascending: true` - 升序（低值优先，适合估值因子）
- `ascending: false` - 降序（高值优先，适合盈利因子）

示例：
1. 股息率，降序，权重 0.6
2. 净资产收益率，降序，权重 0.4

**您的排序规则**：
1. [因子名称]，[升序/降序]，权重 [0-1]
2. [因子名称]，[升序/降序]，权重 [0-1]
3. ...

## JSON 转换规则

### 筛选条件转换
```
自然语言：市盈率 < 20
JSON：
{
  "operator": "less_than",
  "factor": {"type": "fundamental", "name": "pe_ratio"},
  "rhs": 20
}
```

### 排序规则转换
```
自然语言：股息率，降序，权重 0.6
JSON：
{
  "factor": {"type": "fundamental", "name": "dividend_yield"},
  "ascending": false,
  "weight": 0.6
}
```

## 使用步骤

1. **选择种子方向**：根据投资目标选择合适的种子文件
   - `seed_config.json` - 低估值高股息（默认）
   - `seed_smallcap_value.json` - 小盘价值
   - `seed_largecap_growth.json` - 大盘成长
   - `seed_dividend.json` - 高股息红利

2. **或创建新种子**：
   - 填写本模板
   - 转换为 JSON 格式
   - 保存为 `seed_<your_name>.json`

3. **初始化实验**：
   ```bash
   python setup.py --name my_experiment --seed smallcap_value
   ```

4. **开始迭代优化**

## 注意事项

### 指标名称规范
- 使用英文下划线命名（如 `pe_ratio`、`dividend_yield`）
- 参考"常用指标参考表"中的标准名称
- 更多因子见 [WIZARD_GUIDE.md](./WIZARD_GUIDE.md) 因子库完整列表

### 探索方向约束
- `description` 字段会指导 agent 探索方向
- 请确保描述清晰、准确，避免 agent 探索偏离预期
- 例如："小盘价值"应明确限定 universe 为中证1000，估值因子为主

### 权重约束
- 排序权重建议总和约 1（系统会自动归一化）
- 评分权重总和必须为 1
