# 实盘策略配置方案对比

## 方案对比表

| 方案 | 逻辑 | 优点 | 缺点 |
|------|------|------|------|
| **1. 按市场风格选** | 趋势上涨用进攻，震荡用稳健 | 跟随市场，理论上收益最高 | 风格切换时机难判断，可能两边打脸 |
| **2. 按自己风险偏好选** | 保守就全仓稳健，激进就全仓进攻 | 简单，匹配自身需求 | 市场不适配时亏损大 |
| **3. 互补型（反向/低相关）** | 进攻 + 稳健 + ETF 同时跑 | 降低波动，对冲风格切换风险 | 需要管理多策略，可能互相抵消 |
| **4. 核心+卫星** | 主仓用稳健底座，卫星仓位配进攻 | 兼顾稳定性和弹性 | 配比难把握 |
| **5. 风险平价** | 按波动率分配权重，让各策略风险贡献相等 | 科学分散风险，不依赖预测 | 需要持续再平衡，低波动策略权重过高 |
| **6. 目标波动率** | 设定目标波动率（如15%），动态调整仓位 | 风险可控，波动稳定 | 需要频繁调仓，极端行情可能失效 |
| **7. 趋势跟踪叠加** | 用趋势指标（如RSRS、MA）决定总仓位 | 有系统性风控，避免大回撤 | 趋势判断有滞后，震荡市反复打脸 |
| **8. 定期再平衡** | 固定配比（如50/50），定期（如季度）再平衡 | 强制低买高卖，纪律性强 | 再平衡时点可能不是最优 |
| **9. 渐进式建仓** | 先小仓位验证，逐步加仓到目标配比 | 降低初期判断错误成本 | 可能错过初期行情，需要持续跟踪 |
| **10. 策略轮动** | 根据近期表现（如3个月夏普）动态调整权重 | 追逐表现好的策略 | 可能追涨杀跌，需要足够长的观察期 |

## 针对你的RFScore7变种的推荐

### 保守型投资者（最大回撤<15%）
**推荐：方案4（核心+卫星）**
- 核心70%：V3 静态60/40 或 RFScore PB10 Final
- 卫星30%：#85 稳健型ETF策略
- 逻辑：双稳健叠加，ETF作为极端行情缓冲

### 平衡型投资者（最大回撤15-25%）
**推荐：方案4 + 方案8**
- 核心60%：V3 静态60/40
- 进攻20%：V1 RFScore7 纯进攻
- ETF 20%：#85 稳健型ETF
- 每季度再平衡

### 激进型投资者（最大回撤>25%）
**推荐：方案4（调整配比）**
- 核心40%：V3 静态60/40
- 进攻40%：V1 纯进攻 或 主仓动态路由V1
- RSRS 20%：RFScore + RSRS veto（宏观对冲）

## 关键决策因素

| 因素 | 影响 |
|------|------|
| **资金规模** | 小资金适合集中，大资金必须分散 |
| **投资期限** | 短期（<1年）避免进攻型，长期可承受波动 |
| **现金流需求** | 需要定期提取的，降低进攻型比例 |
| **心理承受力** | 即使说能承受25%回撤，实际20%就慌了的，选更保守方案 |
| **时间精力** | 没时间管理的，选方案2或简单版方案4 |

## 我的建议

**不要选方案1**（风格切换太难）
**不要纯方案2**（单一策略风险大）
**推荐方案4（核心+卫星）+ 方案8（定期再平衡）的组合**

具体配比取决于你的回撤容忍度和投资期限。
