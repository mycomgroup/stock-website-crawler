# 果仁策略种子配置生成模板

## 使用说明

本模板用于通过自然语言描述生成果仁策略的种子配置文件 (`seed_config.json`)。

**持仓数量**: [5-30 只股票]

- **操作符**: >
- **阈值**: 2
- **说明**: 筛选高分红股票,股息率大于 2%

## 常用指标参考

### 估值指标
- `pe_ttm`: 市盈率(TTM)
- `pb`: 市净率
- `ps`: 市销率
- `pcf`: 市现率

### 盈利指标
- `roe`: 净资产收益率
- `roa`: 总资产收益率
- `eps`: 每股收益
- `net_profit_margin`: 净利润率

### 成长指标
- `revenue_growth`: 营业收入增长率
- `profit_growth`: 净利润增长率
- `eps_growth`: 每股收益增长率

### 红利指标
- `dividend_yield`: 股息率
- `dividend_payout_ratio`: 分红率

### 财务质量指标
- `debt_to_asset_ratio`: 资产负债率
- `current_ratio`: 流动比率
- `quick_ratio`: 速动比率
- `operating_cash_flow`: 经营现金流

### 市场指标
- `turnover_rate`: 换手率
- `market_cap`: 总市值
- `circulation_market_cap`: 流通市值
- `volume`: 成交量

## 生成 seed_config.json 的步骤

1. 填写上述模板的所有章节
2. 使用 AI 或脚本将模板转换为 JSON 格式
3. 验证 JSON 格式的正确性
4. 保存为 `seed_config.json`
5. 使用 `python init_experiment.py --name <实验名称> --seed-config seed_config.json` 初始化实验

---

## 注意事项

1. **指标名称**: 必须使用果仁网支持的指标名称,参考 `skills/guorn_strategy/GUORN_INDICATORS_CATALOG.md`
2. **权重之和**: 所有排序规则的权重之和应为 1.0
3. **阈值范围**: 确保阈值在合理范围内,避免筛选出空集
4. **调仓周期**: 过短的调仓周期会增加交易成本,过长的调仓周期会降低策略灵活性
5. **持仓数量**: 持仓数量应与股票池大小匹配,避免过度集中或分散
