# Requirements: 弱因子组合量化策略 v2

## 概述

本需求文档从设计文档（design.md）提炼，描述弱因子组合量化策略 v2 的功能需求与验收标准。核心目标是实现"分层收缩合成 + OOF叠加 + 成本感知组合优化"的生产级 A 股弱因子合成框架，彻底替代 v1 中固定三路融合、IC top-k 激活和因子层止损的不成熟设计。

---

## 需求 1：数据治理与点时一致性（L0）

**用户故事**：作为量化研究员，我需要一个点时一致的因子面板，确保回测中任何时间点 t 的数据都只包含 t 时刻真实可得的信息，避免未来信息泄漏导致回测虚高。

### 验收标准

1. 系统能从 `train_merged_all.csv` 加载数据，将 `Unnamed: 0` 重命名为 `stock_id`，`date` 解析为日期类型，按 `[date, stock_id]` 排序。
2. 系统能构建可交易掩码，过滤以下情形：ST/*ST 股票、停牌股票、涨跌停一字板、上市不足 60 个交易日的新股、退市整理期股票。
3. 财务因子必须按实际披露日生效，不允许按报告期末提前生效。
4. 任何使用全样本均值/标准差的预处理步骤均被禁止（通过代码审查验证）。
5. 对随机打乱未来标签后重新运行 pipeline，OOF IC 应接近 0（|IC| < 0.005），证明无未来信息泄漏。

## 需求 2：因子预处理（L1）

**用户故事**：作为量化研究员，我需要对每个再平衡日的因子截面执行标准化预处理，确保弱因子能稳定叠加，且预处理结果不依赖未来数据。

### 验收标准

1. **去极值**：对每个因子按日截面执行 robust winsor，截断范围为 `median ± 5 * MAD`，不使用全局 clip。
2. **缺失处理**：
   - 财务类因子（basics、quality、growth、pershare）：用行业内中位数填补。
   - 微观结构类因子（emotion、technical）：用近期可得值前推（forward fill）。
   - 缺失率超过 30% 的因子降权或移除。
   - 禁止对所有因子统一 `fillna(0)`。
3. **双轨标准化**：同时生成 rank 表示（`rank(x)/(N+1) - 0.5`）和 robust zscore 表示（`(x - median) / (MAD + eps)`）。
4. **风格中性化**：对每个因子单独执行横截面 WLS 回归残差化，右侧暴露集合包含：行业哑变量（申万一级）、`ln(float_mcap)`、`beta`（rolling 60日）、`residual_vol`（rolling 60日）、`liquidity`（换手率 rolling 均值）。WLS 权重为 `sqrt(float_mcap)` clip 后的值。
5. 预处理后缺失率不高于预处理前（单调性约束）。
6. 中性化后的因子与风险暴露的截面相关性绝对值 < 0.05。

## 需求 3：因子家族划分与冗余压缩（L2）

**用户故事**：作为量化研究员，我需要将 260 个因子按经济含义分成若干家族，并在组内压缩冗余，以便后续分层合成能利用独立信息而非重复信号。

### 验收标准

1. 系统冻结以下 9 个经济家族作为第一阶段底板：`basics`（36个）、`emotion`（36个）、`growth`（9个）、`momentum`（34个）、`pershare`（15个）、`quality`（67个）、`risk`（12个）、`style`（30个）、`technical`（16个）。
2. 所有因子恰好属于一个家族（完备性：`union(families) == set(all_factors)`，无重叠）。
3. 系统能计算每个家族的有效维度：`n_eff = (Σλ_j)² / Σλ_j²`，其中 `λ_j` 为家族内截面 rank IC 相关矩阵的特征值，且 `n_eff ≤ 家族因子数`。
4. 家族内截面相关性长期高于 0.8 的因子对，系统能识别并标记为冗余候选。
5. 家族划分定义只在季度或半年级别更新，不做日更或月更（通过版本控制验证）。
6. 系统提供家族划分敏感性测试：将边界因子随机扰动到相邻家族，最终 OOF IC 变化 < 10%。

## 需求 4：组内合成（L3）

**用户故事**：作为量化研究员，我需要对每个因子家族生成一个稳定的代表分数，通过 OOF 叠加三类子分数，避免样本内过拟合。

### 验收标准

1. 对每个家族 g，系统并行计算三类子分数：
   - `s_eq_g`：家族内 rank 等权平均（稳健基线）。
   - `s_ridge_g`：rolling ridge 预测下期残差收益（监督收缩）。
   - `s_pc_g`：PC1 分数，含符号锚定（去冗余）。
2. **PC1 符号锚定**：每个窗口的 PC1 与上一窗口 PC1 相关性为负时，自动乘以 -1；首窗口以等权基线 `s_eq_g` 为方向锚。
3. **PC1 失稳处理**：当第一特征值与第二特征值比值 < 1.5，或 PC1 跨期相关性 < 0.7 时，降权或停用 PC1，回退到 `equal-rank + ridge`。
4. 三类子分数通过非负 ridge（`nonneg_ridge`）做 OOF 叠加，叠加权重由 OOF 结果决定，不使用样本内拟合值。
5. 组内合成的 OOF 预测不使用未来标签（因果性验证：预测值仅依赖 `date < t - embargo` 的数据）。
6. 组内合成分数在标准化后绝对值 ≤ 3.0。

## 需求 5：组间收缩合成——主模型（L4）

**用户故事**：作为量化研究员，我需要将 G 个家族分数通过收缩法合成最终线性 alpha，这是整套方案的核心，必须使用 OOF 输入并通过 inner loop 选择超参数。

### 验收标准

1. 主模型使用 rolling ridge 或 elastic net：`min_β ||y^(h*) - S̃·β||² + λ_ridge·||β||² + λ_lasso·||β||₁`，其中 `S̃` 必须是已经过 horizon-consistent 校准的历史 OOF 家族分数矩阵，禁止使用样本内拟合值。
2. 超参数通过 inner loop 选择：`alpha_reg` 网格 `[0.001, 0.01, 0.1, 1.0, 10.0]`，`l1_ratio` 网格 `[0.0, 0.1, 0.5]`。
3. 家族权重 `β_{t,g}` 满足以下约束：单家族权重上限 0.4，时间上平滑（指数平滑半衰期 4 个再平衡周期），轻度允许负权。
4. 最终线性 alpha：`alpha_linear[t,i] = Σ_g β_{t,g} · s_g[t,i]`。
5. 相邻时间窗口的家族权重变化有界（`||β_t - β_{t-1}||₂ ≤ max_weight_change`）。
6. 禁止使用以下替代方案作为主模型：固定 40/30/30 权重、近期 IC top-k 激活、因子波动率倒数加权。

## 需求 6：非线性残差增强（L5，可选）

**用户故事**：作为量化研究员，我需要一个可选的非线性增强模块，仅在 OOF 验证证明有增益时才启用，且只做线性主模型的残差补充，不接管整个 alpha。

### 验收标准

1. 非线性模型（GBDT）只拟合线性主模型的残差：`r_residual = y - alpha_linear`，不直接预测原始收益。
2. 最终 alpha：`alpha_final = alpha_linear + η · alpha_nonlinear`，其中 `η` 通过 inner loop 从网格 `[0, 0.05, 0.10, 0.20, 0.30]` 中选择，`η=0` 必须永远保留为合法选项。
3. 只有满足以下全部条件时，才允许 `η > 0`：
   - OOF 成本后 IR 相比 `η=0` 有稳定提升（> 5%）。
   - 提升在多数 outer folds 上方向一致。
   - block-bootstrap 检验支持增益为正（p < 0.1）。
   - 换手上升在可接受范围内（< 20% 相对增幅）。
4. 第一阶段（Phase 1）默认关闭，`η` 固定为 0。
5. 非线性模型的 OOF 预测不使用未来标签（因果性验证同 L3/L4）。

## 需求 7：软性 Regime Overlay（L6，可选）

**用户故事**：作为量化研究员，我需要一个可选的市场状态调节模块，只做轻量软调节，不做手工硬切换，避免 hindsight bias。

### 验收标准

1. Regime overlay 只输出单一全局调节系数 `adj_t`，不对不同家族做独立调节（第一阶段）。
2. 调节系数通过低自由度映射生成：`adj_t = clip(a + b · z_regime_t, lower, upper)`，参数 `a, b` 在 inner loop 中选择。
3. 默认调节区间为 `[0.9, 1.1]`，只有在样本外证据明确后才放宽到 `[0.75, 1.25]`。
4. 禁止手工划分牛熊阶段并硬切换主模型。
5. 第一阶段（Phase 1）默认关闭。

## 需求 8：成本感知组合优化（L7）

**用户故事**：作为量化研究员，我需要一个独立的组合优化层，将 alpha 分数转换为真实持仓权重，显式考虑风险、成本和约束，不在因子合成层做止损或杠杆控制。

### 验收标准

1. **层次分离**：因子合成层（L1-L6）只输出 `alpha_score[t,i]`，组合构建层（L7）才输出权重 `w[t,i]`。禁止将因子合成输出直接当仓位使用。
2. **优化目标**：`max_w alpha_t'w - λ_risk·w'Σ_t·w - λ_tc_l1·||w-w_prev||₁ - λ_tc_l2·||w-w_prev||₂² - λ_hhi·||w||₂²`。
3. **约束条件**（全部满足）：
   - `w_i ≥ 0`（long-only）
   - `Σw_i = 1`
   - `w_i ≤ 0.03`（单票上限 3%）
   - 行业偏离 ≤ 5%
   - 总换手 ≤ 30%/月
   - 不可交易股票权重冻结（`w_i = w_prev_i`）
   - 前10持仓集中度 ≤ 20%
4. **简化实现**：当 cvxpy 不可用时，提供 top-N 等权替代方案（过滤不可交易 → 按 alpha 排序取 top-N → 等权分配 → 应用单票上限）。
5. 优化后权重满足所有约束（可通过属性测试验证）。
6. 不可交易股票的权重保持不变（`NOT tradable[t,i] ⟹ w[t,i] == w[t-1,i]`）。
7. 止损、波动率目标、杠杆控制属于组合层应急开关，不在因子合成层实现。

## 需求 9：嵌套 OOF Walk-Forward 验证

**用户故事**：作为量化研究员，我需要一个严格的嵌套 walk-forward 验证框架，确保所有模型的训练和评估都满足时间因果性，避免样本内过拟合和数据窥探。

### 验收标准

1. **Outer loop**（模拟真实研究时点）：
   - 最小训练期：260 个周度样本（约5年）。
   - outer test block：52 个周度样本（约1年）。
   - 推进步长：4 周。
   - embargo：至少 1 个周度样本，防止标签重叠泄漏。
2. **Inner loop**（超参数选择）：
   - 只在 outer-train 内部运行，不使用 outer-test 信息。
   - validation block：13 个周度样本。
   - 必须在 inner loop 中选择：收缩强度、`η`、成本惩罚强度、约束松紧。
3. **OOF 构造**：每个 `(date, stock)` 样本恰好有一个 OOF 预测，来自不包含该样本及其泄漏邻域的模型。
4. **Embargo 下限**：`embargo ≥ max(label_horizon, execution_delay, feature_publication_lag)`。
5. **超参数稳定化**：相邻 outer windows 的超参数通过指数平滑稳定化，禁止使用未来窗口信息（`θ_t = f(θ_t*, θ_{t-1}, ...)`）。
6. **Final holdout**：最后约 104 周在研究阶段完全冻结，只在最终上线前查看一次，禁止在 final holdout 上反复调参。
7. 所有叠加器（组内 stack、组间 stack、非线性 overlay、regime 调节）的训练输入必须是历史 OOF 预测，不允许使用样本内拟合值。

## 需求 10：评估指标体系

**用户故事**：作为量化研究员，我需要一套多维度的评估指标，覆盖因子层、合成层、组合层和稳健性，不能只看 IC 和夏普比。

### 验收标准

1. **因子层指标**：rank IC、ICIR、partial rank IC、单调分组收益、增量解释力、稳定性与符号一致性。
2. **合成层指标**：OOF rank IC、decile spread、信息比、家族权重稳定性、有效 breadth、信号自相关与换手。
3. **组合层指标**：税费后 Sharpe/IR、最大回撤、月度胜率、换手率、容量、风险暴露偏离、成本占 alpha 比例。
4. **稳健性指标**：不同年份表现、牛熊子样本表现、大小盘分层表现、行业分层表现、延迟执行1天后表现、参数扰动后表现、删掉最强10%因子后表现。
5. **上线闸门**（6项硬性 gate，全部通过才允许上线）：
   - 税费后结果成立。
   - 延迟执行1天后结果仍成立。
   - 容量测试不过度衰减（资金规模放大10x后 alpha 衰减 < 30%）。
   - 风险暴露可解释且可控。
   - 参数扰动后不脆弱（删掉最强10%因子后仍成立）。
   - final holdout 不弱于 research OOS 的可接受区间。

## 需求 11：正确性属性（Property-Based Testing）

**用户故事**：作为量化研究员，我需要一套可执行的正确性属性，通过属性测试（PBT）持续验证系统的关键不变量，确保重构后的代码满足设计规范。

### 验收标准

1. **P1 点时一致性**：`∀t,i,k: X_clean[t,i,k]` 仅依赖 `date ≤ t` 的数据。验证方法：随机打乱未来标签后 OOF IC 接近 0。
2. **P2 截面标准化幂等性**：对已标准化数据再次标准化，结果不变（数值精度范围内）。
3. **P3 去极值有界性**：`∀t,k: max(|X_winsor[t,:,k] - median_k|) ≤ 5 * MAD_k + eps`。
4. **P4 中性化残差正交性**：`∀k: |corr(X_neu[t,:,k], B[t,:,m])| < 0.05 ∀m`。
5. **P5 家族完备性**：`union(family_map.values()) == set(all_factors)`，无重叠，无遗漏。
6. **P6 OOF 无泄漏**：`∀t: prediction[t]` 仅依赖 `date < t - embargo` 的数据。
7. **P7 权重合法性**：`∀t: Σw_i=1, ∀i: 0≤w_i≤0.03, 不可交易股票权重冻结`。
8. **P8 换手有界性**：`∀t: Σ|w_i[t] - w_i[t-1]| ≤ max_turnover`。
9. **P9 参数扰动稳健性**：删掉最强10%因子后，OOF IC 衰减 < 20%（`IC(top_90%) / IC(all) > 0.80`）。
10. **P10 延迟执行稳健性**：延迟执行1天后，税费后 Sharpe 衰减 < 15%（`Sharpe(delay=1) / Sharpe(delay=0) > 0.85`）。

## 需求 12：工程与可复现性

**用户故事**：作为量化研究员，我需要系统具备工程可持续性，支持增量计算、结果落盘和版本追踪，确保研究可复现。

### 验收标准

1. 因子面板、风险暴露、标签和成本数据分层缓存，支持增量更新。
2. OOF 结果、inner loop 结果、outer loop 结果分别落盘，支持断点续跑。
3. 每个研究版本保留参数快照、数据版本和随机种子，确保完全可复现。
4. 大矩阵计算（500因子 × 4000+股票 × 嵌套CV）支持分块读取和并行化。
5. 代码通过固定随机种子（`random_state=42`）可完全复现结果。

## 禁止事项（明确不允许的设计）

以下设计在 v2 中明确禁止，违反任何一项均视为需求未满足：

| 禁止项 | 原因 |
|--------|------|
| 全样本标准化 | 引入未来信息 |
| 直接按近期 IC 排名激活 top-k 因子 | 追噪声，抖动大 |
| 手工划牛熊阶段并硬切主模型 | hindsight bias |
| 固定 40/30/30 三路融合 | 不考虑预测力差异 |
| 因子波动率倒数作为核心权重 | 理论弱，易错配 |
| 把因子合成输出直接当仓位 | 层次混乱 |
| 在因子层做止损和杠杆控制 | 止损属于组合层 |
| 只看样本内夏普、只留1~2年尾部样本外 | 不充分的样本外验证 |
| 非线性模型直接作为主模型 | 应降级为 residual overlay |
| 在 final holdout 上反复调参 | data snooping |

## 需求 13：Freshness Decay 与多频率因子对齐

**用户故事**：作为量化研究员，我需要对低频因子的信息时效性进行建模，确保过时的财务因子不会以原始权重进入合成层，同时避免直接改写因子值。

### 验收标准

1. 系统能计算每个因子在每个再平衡日的 `age_in_days`（距上次更新的天数）。
2. Freshness decay 权重公式：`c_{g,t} = exp(-age_{g,t} / tau_g)`，其中 `tau_g` 是家族特征衰减时间常数。
3. **禁止**将 `c_{g,t}` 直接乘到原始因子值上（`x * c` 是错误用法）。
4. `c_{g,t}` 只允许用于以下三种方式之一：作为额外特征输入模型、作为组内/组间分数的置信度权重、作为 horizon calibration 的附加输入。
5. 通过 inner loop 比较"无 freshness 处理"和"有限 freshness 处理"两种版本，由 OOF 结果决定是否启用。
6. 第一阶段（Phase 1）可暂不实现，Phase 2 引入。

---

## 需求 14：存活偏差与退市收益处理

**用户故事**：作为量化研究员，我需要确保回测数据集正确处理退市股票，避免因静默丢弃退市样本导致回测系统性高估。

### 验收标准

1. 系统明确记录训练和测试截面中是否包含后来退市的股票。
2. 退市前最后一段收益若数据可得，必须纳入训练样本；若数据缺失，记录缺失原因和处理方式。
3. 退市整理期股票在可交易掩码中标记为不可交易，权重冻结（`w_i = w_prev_i`）。
4. 暂停上市后重新上市的股票，按重新上市日期重新计算冷启动期（≥ 60 个交易日）。
5. 提供存活偏差检查报告：对比"含退市样本"和"不含退市样本"的 OOF IC 差异，差异 > 5% 时发出警告。

## 需求 15：Data Snooping 防控

**用户故事**：作为量化研究员，我需要在多次尝试不同因子、标签和参数组合时，有统计方法控制 false discovery，确保最终结果在严格控制试错次数后仍然成立。

### 验收标准

1. 系统支持 block bootstrap 或 moving block bootstrap 统计检验，用于评估 OOF IC 的统计显著性。
2. 在"模型家族选择"和"最终候选模型比较"两个节点执行 multiple testing 调整（Bonferroni 或 BH 校正）。
3. 不同研究分支共享统一的最终样本外窗口，禁止各分支使用不同的 final holdout 区间。
4. 系统记录每次 final holdout 的访问次数，超过 1 次时发出警告。
5. 可选：实现 White's Reality Check 或 SPA（Superior Predictive Ability）检验，用于多模型比较。

## 需求 16：风格中性化规范（补充）

**用户故事**：作为量化研究员，我需要风格中性化的实现严格遵循技术方案规范，避免路径依赖和矩阵近奇异问题。

### 验收标准

1. **禁止逐步回归**：不允许按"先市值、再行业、再 beta"的顺序逐步回归，必须对每个因子单独回归，右侧使用**同一组联合风险暴露**（联合回归）。
2. **样本极少行业处理**：当某行业样本数 < 10 时，使用行业合并（合并到相邻行业）或 ridge 回归，避免回归矩阵近奇异。
3. **行业哑变量写法统一**：全框架统一使用 `K-1` 个行业哑变量 + 截距，或 `K` 个哑变量无截距，两种写法不可混用。
4. **跨时间估计暴露的因果性**：`beta`、`residual_vol` 等 rolling 估计的暴露，其估计窗口必须严格因果（只使用 `date < t` 的数据）。行业哑变量和当日市值是点时可得的，不需要额外 OOF。
5. 中性化后的因子与风险暴露的截面相关性绝对值 < 0.05（验证联合回归的正确性）。

## 需求 17：Horizon Calibration（补充）

**用户故事**：作为量化研究员，我需要将不同家族在各自 native horizon 上训练的 OOF 分数，校准到统一的 decision horizon，确保 L4 只对单一标签做回归。

### 验收标准

1. 每个家族先在最合适的 native horizon 上训练，得到 OOF 分数 `s_g^{(h_g)}`。
2. 用仅基于 OOF 样本的校准器，将 `s_g^{(h_g)}` 映射成对统一 decision horizon `h*` 的预测 `s̃_g^{(h*)}`。
3. 校准方法可选：单调回归（isotonic regression）、分桶校准、线性校准。
4. 只有校准后的分数 `s̃_g^{(h*)}` 才允许进入 L4，L4 永远只对单一 decision horizon 的标签 `y^{(h*)}` 做回归。
5. 第一阶段（Phase 1）统一使用单一 decision horizon（1个周期 pchg），不区分 native horizon，horizon calibration 模块暂不启用。
6. Phase 2 引入多 horizon 支持时，必须先实现 horizon calibration 模块。
